# CL-027: Detect a project CLI that lives in a package bin or a named control script

## Goal

The `project_cli` rule finds the project CLIs that real repos use.

## Context

- `clutch doctor` on Bar Savvy `epic/refactor` (2026-10-29) reports `project_cli` missing. The plan says Bar Savvy has the `control-bar-savvy` CLI.
- The rule checks `apps/*/package.json` for `"bin"`, plus a few task-runner files.

## Steps

1. Find where `control-bar-savvy` lives in Bar Savvy and how it runs.
2. Widen the rule in `docs/contributing/capabilities/registry.yaml` to cover it, for example `packages/*/package.json` bins or root `package.json` scripts that start a CLI. Keep the template's expected status in `seed.test.ts`.
3. Run `clutch doctor --root ~/dev/bar-savvy-web` and confirm `project_cli` is present.

## Acceptance criteria

- `project_cli` is present on Bar Savvy and keeps its expected status on the template.
- validate passes.
