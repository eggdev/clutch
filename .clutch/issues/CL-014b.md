# CL-014b: Replace review install with clutch sync --only review and delete the old file lists

## Goal

One sync command. `clutch sync --only review` does what `review install` did, and `template.files.yaml`, `review.files.yaml` and `review-baseline.json` go away.

## Steps

1. Tag the review tooling entries in `clutch.files.yaml` with `group: review`. Move the known older hashes from `review-baseline.json` into `clutch.files.yaml`.
2. Add `--only <group|capability|path>` to `clutch sync`.
3. Port each `review-install.test.ts` test to sync with the same intent. Delete `review-install.ts`, `review-command.ts` and the test in the same change, so `check-test-integrity` allows the deletion. If it still fails, ask Brendan. Do not weaken it.
4. Update every caller of `review install`: docs, skills, the README and the verify journeys.
5. Delete the three old files once nothing reads them. Sync removes `.review/tooling.json` after it writes `.clutch/lineage.json`.

## Acceptance criteria

- `git grep` for the three old file names finds nothing outside `.clutch/`.
- `clutch review install` exits with an unknown-command error.
- validate passes.
