# CL-120: Add one command index and nudge agents toward it

## Goal

Agents find the repeatable command for each step in one index, and a hook nudges them toward it.

## Context

On 2026-10-30, the coordinator audited the 413 shell commands that the lanes ran. Many steps were raw `gh` loops and hand fixes that a `bun run pr` or `clutch` command already does. Brendan wants every addition repeatable in each project, and documented so agents reuse it.

## Steps

1. Branch `clutch/cl-120-command-index`.
2. Write `.agents/skills/deliver/references/commands.md`. List each repeatable command by stage, with when to use it and what it replaces. Add a "do not hand-roll" list.
3. Link it from the deliver skill, `.agents/skills/README.md`, `apps/cli/README.md`, `AGENTS.md` and the tracker README that `clutch init` writes.
4. Hint, never block, when an agent runs `gh pr checks`, `gh pr merge`, `gh stack merge` or `gh run view --log`.
5. Check each documented command in a scratch project from the latest release.

## Files

- `.agents/skills/deliver/references/commands.md`, `tools/agent-hooks/command-nudges.ts`, `tools/agent-hooks/guard-dev-servers.ts`, `tools/github/pr.ts`.

## Acceptance criteria

- Each command in the index resolves in a project, with `--help` or a dry run.
- The hook hint names the replacing command, and the raw command still runs.

## Verify

```bash
mise exec -- bun test tools/agent-hooks tools/github/pr.test.ts
```
