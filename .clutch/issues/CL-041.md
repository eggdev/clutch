# CL-041: Let gardening pull requests pass the gates

## Goal

A pull request that the gardening workflow opens can pass every required check, so a person only has to read it.

## Context

The first real gardening run on 2026-10-30 opened PR #55 with the release bot token (CL-039), and CI ran on it. Two checks failed for reasons outside the edit. `check-changeset` failed, because the workflow writes no changeset. `agent-review` failed, because the Claude action refuses a PR that a bot opened unless `allowed_bots` names the bot.

## Steps

1. `gardening.yml`: write `.changeset/gardening-<date>.md` before the commit, with the bump rule of `tools/github/pr.ts`. Ask the agent for a conventional title.
2. `agent-review.yml`: set `allowed_bots: '*'`. A fork PR gets no secrets, so this reaches only bots inside the repository.

## Files

- `.github/workflows/gardening.yml`, `.github/workflows/agent-review.yml`

## Acceptance criteria

- The next gardening PR passes `validate` and `agent-review`.

## Verify

```sh
gh workflow run gardening.yml
gh pr checks <the gardening PR>
```
