# CL-477: Do not free the auth paths on a journey that proves nothing

## Goal

A risk rule frees its paths only when each named journey is not a draft and asserts something.

## Context

- A risk rule with `journeys:` stops holding its paths when each named journey exists.
- The check is `journeysPresent` in `apps/cli/src/risk/tiers.ts`.
- `tools/codeowners.ts` has a copy of that check.
- `tools/github/weaker-journeys.ts` does not compare a new journey file.
- A draft journey counts as present. Issue CL-465 fixes that.
- So a placeholder `sign-in` journey could free `**/auth/**`.

## Steps

1. Branch `clutch/cl-477-journey-must-assert`.
2. Change `journeysPresent` so it counts a journey only when it is not a draft and it asserts something. Find out first: how CL-465 marks a draft journey.
3. Make the copy in `tools/codeowners.ts` follow the same rule. Find out first: whether the copy can import the first one.
4. Add tests for a draft journey, for a journey that asserts nothing, and for a journey that asserts something.

## Files

- `apps/cli/src/risk/tiers.ts`
- `tools/codeowners.ts`
- `tools/github/weaker-journeys.ts`

## Acceptance criteria

- A placeholder journey does not free `**/auth/**`.
- A journey that is not a draft and asserts something still frees its paths.
- Both copies give the same answer.
