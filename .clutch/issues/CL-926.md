# CL-926: Give each machine its own port on the build machine for the dev server link

## Goal

Two machines run native journeys at the same time, and the build machine can run its own dev servers too.

## Context

The dev server link of CL-594 forwards the port of the dev proxy, 1355, from the build machine to one machine. The app's bundle holds that port. So one machine at a time can hold it, and the dev servers of the build machine itself take the same port. The link refuses the second caller with a message. A forward also stays up after a run, until either machine restarts.

Hot reload does not reach a pool device: the app shows "[vxrn HMR]: connection error" in a toast. A relaunch loads the new JavaScript.

## Steps

1. Give each machine its own proxy port, or give the app its origin in another way, such as an HTTPS name on the tailnet.
2. Decide whether hot reload on a pool device is worth a second forward.

## Files

- `tools/native/dev-link.ts`, `tools/dev.ts`

## Verify

Run the journey from two machines at once.
