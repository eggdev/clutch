# CL-042: Run every action on Node.js 24 and pin the Ubuntu 26.04 runner

## Goal

Every workflow runs on current action runtimes and on a runner image that a reviewed PR chose.

## Context

GitHub ends the Node.js 20 runtime for actions, and the `ubuntu-latest` label moves to Ubuntu 26 from 2026-10-19 (actions/runner-images#14748). Brendan asked for Node.js 26 where possible. On 2026-10-30, no action that Clutch uses offers `node26`, not even on its main branch, so Node.js 24 is the newest runtime. `anthropics/claude-code-action@v1` is a composite action, so it has no runtime of its own.

## Steps

1. Move each action to its newest major, all on `node24`: `actions/checkout@v7`, `actions/cache@v6`, `actions/upload-artifact@v7`, `actions/create-github-app-token@v3` and `jdx/mise-action@v5`. The inputs that Clutch passes still exist in each.
2. Replace `runs-on: ubuntu-latest` with `runs-on: ubuntu-26.04` in every job.
3. Document both rules in the CI section of `docs/contributing/setup/checks.md`.
4. CL-103 pins the new majors to commit SHAs.

## Files

- `.github/workflows/*.yml`
- `docs/contributing/setup/checks.md`, `.clutch/issues/CL-501.md`

## Acceptance criteria

- Every CI job on this PR runs on `ubuntu-26.04` and passes, the journeys job included.
- The release after the merge publishes with `create-github-app-token@v3`.

## Verify

```sh
grep -rhoE "uses: [^ ]+|runs-on: [^ ]+" .github/workflows/ | sort | uniq -c
gh pr checks <this PR>
```
