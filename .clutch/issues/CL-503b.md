# CL-503b: Add PR size and agent share to clutch metrics

## Goal

The weekly metrics show how big agent PRs are and how many come from agents.

## Steps

1. Branch `clutch/cl-503b-metrics-size-share`.
2. Extend `clutch metrics` (CL-503) with two fields:
   - Median PR size, counted the same way as `clutch pr-size` (CL-401).
   - The agent share: the PRs whose head branch starts with `clutch/cl-`, the rule from CL-404. The PR author cannot tell agents apart, because `pr open` runs under the operator's `gh` login.
3. Every `gh api` call takes `--repo OWNER/NAME`.

## Acceptance criteria

- `clutch metrics --json` returns both new fields for the template repo.

## Verify

```bash
mise exec -- bun run clutch metrics --since 30d --json | jq
```
