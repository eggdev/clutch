# CL-502: Add a nightly flake hunter

## Goal

Find flaky tests before they block PRs.

## Steps

1. Branch `clutch/cl-502-flake-hunter`.
2. Add `.github/workflows/flake-hunt.yml`, the name that `docs/contributing/capabilities/flake-hunter.md` gives. Trigger on `schedule` (nightly) and `workflow_dispatch:`.
3. The job runs `bun test --rerun-each 20 tools --path-ignore-patterns 'tools/lint/**'`. That is the `test` target's command in `package.json`, with the rerun flag and the count from the capability doc.
4. When a test fails on some runs and passes on others, the job opens a PR that adds a quarantine entry to `tools/flaky-tests.json`, with a new issue.
5. Open that PR with the GitHub App token that the gardening job gets from the Claude action, not `GITHUB_TOKEN`. A PR that `GITHUB_TOKEN` opens starts no CI.
6. Set `flake_hunter` to `adopted` in `clutch.yaml`, and run `mise exec -- bun run clutch doctor --write-baseline`.

## Acceptance criteria

- A seeded flaky test in a scratch branch gets detected.
- The PR it opens runs CI.

## Verify

```bash
gh workflow run flake-hunt.yml --ref clutch/cl-502-flake-hunter && gh run watch
```
