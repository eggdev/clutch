# CL-502: Add a nightly flake hunter

## Goal

Find flaky tests before they block PRs.

## Steps

1. Branch `clutch/cl-502-flake-hunter`.
2. Add `.github/workflows/flake-hunter.yml` on a nightly schedule. It runs `bun test --rerun-each 5` on the test projects. When a test fails sometimes and passes sometimes, it opens a PR that adds a quarantine entry with a new issue.

## Acceptance criteria

- A seeded flaky test in a scratch branch gets detected.

## Verify

```bash
gh workflow run flake-hunter.yml --ref clutch/cl-502-flake-hunter && gh run watch
```
