# CL-323: Remove the five stage agents

## Goal

Clutch has one way to move work through steps: the phases of a ticket.

## Context

Clutch has five stage agents: triage, spec, implement, review and verify. Each has a file in `factory/agents/`. `clutch agent mark` records a stage in a pull request comment or in `clutch-stages/` in the git common directory. The owner decided on 2026-11-21 to delete them, because they do not work yet and the phases of CL-318 replace them.

## Steps

1. Branch `clutch/cl-323-remove-stage-agents`.
2. Delete `factory/agents/`, and the `clutch agent mark`, `prompt` and `run` commands in `apps/cli/src/agent/`.
3. Delete `docs/contributing/stage-agents.md`, and remove each reference to a stage in the `deliver` and `run-lanes` skills and in the docs.
4. Remove the readers of the stage markers: the metrics, and each check that names a stage.
5. Keep the rest of `factory/` only where another command still reads it. Delete what nothing reads.
6. Tell the owner what C-Suite still expects from the stage markers, so the owner can decide what to do there.

## Files

- `factory/agents/`, `apps/cli/src/agent/`, `apps/cli/src/commands.ts`
- `docs/contributing/stage-agents.md`, `.agents/skills/deliver/`, `.agents/skills/run-lanes/`

## Acceptance criteria

- `clutch agent` prints an unknown command error.
- `git grep -n "clutch-stage"` finds nothing.
