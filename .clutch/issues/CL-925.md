# CL-925: Make a native build with no ssh when this machine is the build machine

## Goal

A session on the build machine itself makes a native build and runs a native journey with no ssh call.

## Context

`tools/native/build-machine.ts` reaches the build machine over ssh, and `tools/native/dev-link.ts` forwards a port to it over ssh. A session that runs on the build machine needs neither: Xcode is on the machine, and a simulator reaches its dev servers at `localhost`. Today such a machine must name itself in `~/.config/clutch/build-machine.json` and accept its own key.

## Steps

1. Let the setting say that this machine is the build machine.
2. Run the build script with no ssh, and skip the dev server link.

## Files

- `tools/native/build-machine.ts`, `tools/native/dev-link.ts`
- `docs/contributing/setup/native.md`

## Acceptance criteria

- C1: On the build machine, `native:build --platform ios` makes a build with no ssh call.
- C2: On the build machine, a native journey passes with no forward.

## Verify

Run both on the build machine.
