# CL-302: Add the shrink-only ratchet engine

## Goal

A generic ratchet engine: count violations per file for a named rule, fail when a count rises against the merge base or the baseline, and fail when a count drops and the baseline was not lowered.

## Context

- `apps/cli/src/doctor/baseline.ts` (`nextBaseline`) already refuses a lower-rank write unless `allowDowngrade` is set. Reuse it or extract its logic into a shared helper. Do not write a second version.
- The template has no lint counts to ratchet, so this issue ships only the engine and its tests. The first real consumer is CL-703.
- The commands, the root target and adoption are in CL-302b.

## Steps

1. Branch `clutch/cl-302-ratchet`.
2. Format: `.clutch/ratchets.json` `{schemaVersion:1, ratchets:{<name>:{command|pattern, files: glob, counts:{path: n}}}}`.
   - `pattern` is a regex counted per file.
   - `command` prints `path:count` lines. Use it for oxlint JSON output or tier rules.
3. Add `apps/cli/src/ratchet/*.ts` with the count, compare and update functions. Build the write path on `nextBaseline` from `apps/cli/src/doctor/baseline.ts`.
4. Port the semantics of Bar Savvy `.github/scripts/check-lint-suppressions.cjs`, which counts against the merge base. Read it in `blockmen-group/bar-savvy-web` at `epic/refactor`.

## Acceptance criteria

- Tests cover a raise (fail), a drop without update (exit 2) and a drop with update (pass).
- An update cannot raise a count.
- The update path reuses `nextBaseline` or a helper extracted from it. No copy.
