# CL-103: Pin GitHub Actions to SHAs and lint workflows with actionlint and zizmor

## Goal

Close the `ci_security_lint` gap: every `uses:` pins a full SHA, and workflows pass actionlint and zizmor.

## Steps

1. Branch `clutch/cl-103-pin-actions`.
2. Pin each `uses: owner/action@vN` in `.github/workflows/*.yml` to `@<40-hex sha> # vN`. Resolve each SHA with `gh api repos/<owner>/<action>/git/ref/tags/<tag>`. Dereference annotated tags.
3. Extend `tools/check-workflows.ts` with a rule: a `uses:` ref must be a 40-hex SHA unless it is a local `./` path. Add a fix message and a test in `tools/check-workflows.test.ts`.
4. Pin `actionlint` and `zizmor` in `mise.toml`. Add root target `check-workflow-lint` (`actionlint && zizmor --min-severity medium .github/workflows`) to `checks`, and a row in `checks.md`.
5. Fix every finding, or narrow a permission. Never add an ignore file. Ask Brendan before ignoring anything.
6. Adopt `ci_security_lint`.

## Acceptance criteria

- `rg -n 'uses: [^.].*@v[0-9]' .github/workflows` prints nothing.
- `check-workflows` and `check-workflow-lint` pass.

## Verify

```bash
rg -n 'uses: [^.].*@v[0-9]' .github/workflows
mise exec -- bun nx run-many -t check-workflows check-workflow-lint
```
