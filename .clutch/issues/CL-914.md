# CL-914: Point every skill step at a clutch command, not a handwritten gh or git step

## Goal

The deliver and run-lanes skills name a `clutch` or `bun run pr` command for every step, and no step tells an agent to type `gh` or `git` by hand.

## Context

CL-902 (Brendan, 2026-11-01): Clutch is the primary driver of the workflow. The CL-902 notes list each time an agent ran a step by hand that a command should do.

## Steps

1. List each `gh` and `git` step in `.agents/skills/**`.
2. Point each one at a command, or file an issue for the missing command.

## Trigger

Small enough to take on any time. Kept in `later` until a lane has room.
