# CL-301: Record the ratchet decision and amend the no-baseline rule

## Goal

Brendan decided that ratchets come back. Record the decision and change the docs that forbid baselines.

## Context

- `docs/contributing/harness-engineering.md:127-129` says to turn a rule on everywhere at once, and "Do not keep a baseline file of old violations. It goes stale."
- `docs/contributing/setup/lint-rules.md:17-19` says a rule is on everywhere or off everywhere. It does not use the word "baseline", so change it only to allow the ratchet exception.
- `docs/contributing/capabilities/suppression-discipline.md:18` already says to count suppression comments against a shrink-only baseline.
- `tools/file-size-budgets.json` is already a shrink-only budget per file.
- Decisions live in `docs/contributing/decisions/`. Only `0000-template.md` exists, and `decisions/index.md` says "None yet", so the new record is `0001`. `check-decisions` validates it.
- `decisions/index.md` says not to write a record for a template default. This record is Clutch's own decision to allow downstream ratchets, so it is a valid record.

## Steps

1. Branch `clutch/cl-301-ratchet-decision`.
2. Read `docs/contributing/decisions/0000-template.md` and `tools/check-decisions.ts` for the format. Add `docs/contributing/decisions/0001-allow-shrink-only-ratchets.md` with the title "Allow shrink-only ratchets for adopted repositories". Add it to the steering list in `index.md`. It says:
   - The template ships a zero baseline and no lint baseline. `.clutch/doctor-baseline.json` is the existing exception.
   - A downstream repo may keep a ratchet baseline for a rule it adopts.
   - The baseline may only shrink.
   - It counts against the merge base.
   - It is a guardrail file.
3. Edit `harness-engineering.md`, `lint-rules.md` and `suppression-discipline.md` to match, citing the decision. Keep STE and the doc checks.
4. This changes a guardrail stance, so ask Brendan to review it in the PR.

## Acceptance criteria

- `check-decisions` and the doc checks pass.
- No doc still says "Do not keep a baseline file".
