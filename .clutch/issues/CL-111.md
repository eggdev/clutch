# CL-111: Add a PR babysitter skill that drives a pull request to green

## Goal

Projects get an in-repo skill that takes an open PR to green: it reruns flaky jobs, fixes failures it can fix, answers review findings, and stops with a report when it cannot.

## Context

In the 2026-10-30 research over 58 repositories (see `.clutch/PLAN.md`), 4 of 8 multi-engineer repositories that ship more than their headcount predicts have a PR babysitter, against 1 of 8 that ship less (kibana `.agents/skills/pr-babysit`). Today Clutch relies on the host watcher or the external `monitor-ci` skill, so a project inherits nothing.

## Steps

1. Branch `clutch/cl-111-babysit`.
2. Add `.agents/skills/babysit-pr/SKILL.md` with a `.claude/skills` link. Steps: read `gh pr checks` and the failed logs, classify each failure (flaky, real, setup), rerun flaky jobs once, fix real failures on the branch, answer each agent-review finding, push, and repeat.
3. Cap it at 3 rounds. Then stop and post one comment with what it tried and what is left.
4. Point `.agents/skills/deliver/references/pull-requests.md` at it for the time between open and merge.
5. Add a skill test, as `check-skills` and `tools/run-skill-tests.py` require.

## Files

- `.agents/skills/babysit-pr/`
- `.claude/skills/babysit-pr`
- `.agents/skills/deliver/references/pull-requests.md`

## Acceptance criteria

- The skill passes `check-skills` and its skill test.
- On a PR with a planted lint failure, the skill fixes it and the checks go green.

## Verify

```sh
mise exec -- bun run validate
```
