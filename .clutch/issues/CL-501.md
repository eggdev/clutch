# CL-501: Feed the friction log and flaky registry into weekly gardening

## Goal

The weekly gardening PR fixes the top friction items and the expiring flaky tests.

## Steps

1. Branch `clutch/cl-501-gardening-inputs`.
2. In `.github/workflows/gardening.yml`, add `jdx/mise-action@v2` and `bun install --frozen-lockfile` before the gardening step. The job installs neither today.
3. Add `Bash(mise exec -- bun run clutch friction:*)` to `allowedTools`. `clutch` is not on the job's path, so call it through `mise exec -- bun run clutch`, as the verify commands do.
4. Edit the prompt so it reads `clutch friction list --since 7d --json` and `tools/flaky-tests.json`, and picks at most 3 items.
   - Treat a missing `tools/flaky-tests.json` as an empty list. CL-304 creates it, so it is absent until that lands.
5. Define handled: a friction entry is handled when the gardening edit fixes it. The PR body names each entry by its `at` value, and the same PR removes those lines from `.clutch/friction.jsonl`. CL-306 has no handled field, so `at` is the key.

## Acceptance criteria

- A manual `workflow_dispatch` run opens one PR that references friction entries.

## Verify

Before the run, close any open gardening PR, because the job skips while one is open. Then merge a PR that seeds one friction entry on `main`, because the job checks out the default branch.

```bash
gh workflow run gardening.yml && gh run watch
```
