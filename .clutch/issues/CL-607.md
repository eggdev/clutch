# CL-607: Cut local dev tools from Neighborhood's one-way-door tier

## Goal

Neighborhood's CODEOWNERS holds only its hard core. Local dev tooling merges with no approval.

## Context

CL-419's dry run found nbhd#54 ("read a test sign-in code and trust the stack's origins"). It changed only `tools/dev.ts` and `tools/dev/`, and it waited for Brendan because Neighborhood's `.clutch/risk.yaml` lists them in the infra tier, next to `tools/preview.ts`, `tools/env-file.ts`, `tools/cloud-env.sh`, `.devcontainer/` and `.cursor/environment.json`. Those run on a laptop or in a dev container, with dev credentials. They do not deploy, and they do not touch production secrets. Decision 0002 names infra and deploy, and secrets.

## Steps

1. In Neighborhood's `.clutch/risk.yaml`, move `tools/dev.ts`, `tools/dev/**`, `.devcontainer/**` and `.cursor/environment.json` out of `one-way-door`. Keep `tools/env-file.ts`, `tools/cloud-env.sh`, `**/.env*`, `tools/preview.ts` and `tools/migration-dry-run.ts`. They write secrets or reach a cloud resource.
2. Run `mise exec -- bun tools/codeowners.ts --write`.

## Files

- `.clutch/risk.yaml` and `.github/CODEOWNERS` in eggdev/neighborhood

## Acceptance criteria

- A PR that changes only `tools/dev/` needs no approval.

## Verify

`mise exec -- bun run validate` in Neighborhood.

## Gate

Brendan decides which paths stay. `risk.yaml` is hard core.
