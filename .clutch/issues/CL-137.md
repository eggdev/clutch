# CL-137: Open agent PRs as the release bot, so the owner can approve them

## Goal

Brendan can approve an agent's PR, GitHub requires his approval only on one-way-door PRs, and he stays the author of each commit.

## Context

- GitHub never lets a PR's author approve that PR. `pr open` opened PRs as Brendan, so he could not approve them.
- Agents commit as Brendan, with a `Co-Authored-By` trailer for the agent, so the contribution graph credits him. That stays.
- Brendan's login is an admin, which can bypass the ruleset, so `pr merge` running as Brendan would merge past a required approval.
- Auto-merge, agent review and the labels key on the `clutch/cl-` branch prefix, not on the author.

## Steps

1. Add `open-pr.yml`: `workflow_dispatch` with head, base and title, in the `release` environment. It mints the bot token, checks the head branch, and opens the PR through the API. It never checks out code.
2. `pr open` dispatches it on the default branch, waits for the PR, and sets the body as the user. Without `CLUTCH_APP_ID` or the workflow, or when no PR appears in 3 minutes, it opens the PR as the user.
3. Generate `.github/CODEOWNERS` from the `one-way-door` tier of `.clutch/risk.yaml` with `tools/codeowners.ts`. `check-agent-hooks` fails on drift.
4. Set `require_code_owner_review: true` in `.github/rulesets/main.json`, and apply it with `clutch ruleset --apply` after the merge.
5. `pr merge` refuses while `reviewDecision` is `REVIEW_REQUIRED` or `CHANGES_REQUESTED`, and names the reviewer.
6. After the apply, open a test PR that touches a one-way-door path, check that GitHub requires review with 0 required approvals, then close it.

## Files

- `.github/workflows/open-pr.yml`, `tools/github/{bot-open,pr,merge}.ts` and their tests
- `tools/codeowners.ts`, `tools/check-agent-hooks.ts` and their tests, `.github/CODEOWNERS`, `.github/rulesets/main.json`
- `.agents/skills/deliver/references/{pull-requests,commands}.md`, `docs/contributing/setup/{releases,ci-credentials}.md`

## Acceptance criteria

- A PR that `pr open` opens has the release bot as its author, and Brendan's body.
- A one-way-door PR shows review required. Another PR does not.
- `pr merge` refuses a PR that needs a review.
