# CL-436: Merge, watch main and revert inline in the delivering session

## Goal

The session that builds a change also merges it, watches `main` after the merge, and reverts it when it breaks `main`. No cron or `workflow_run` job decides the merge.

## Context

Brendan, 2026-11-06: each agent that builds something owns its scope through the merge. A scheduled sweep that merges a PR an hour later is not the same as the session that finishes the work. Today the Auto-merge workflow, its hourly sweep, the Grade verdicts workflow and the CI explain workflow do this work in GitHub Actions.

Brendan chose to keep `auto-revert.yml` as a safety net for a session that dies before it sees `main` go red. Agent review stays a pull request check.

## Steps

1. `bun run pr merge <number>` runs the auto-merge judge before it merges. It reads `automerge` from the default branch's `clutch.yaml`, so a PR cannot change its own mode or step. The owner's approval of the head, or `--owner` when the owner said so in the session, skips the judge.
2. After the release, `pr merge` waits for CI on the merge commit. A red run gets one rerun of its failed jobs. A second red run starts the Revert workflow for that PR.
3. `bun run pr revert <number>` starts the Revert workflow by hand.
4. Make `auto-merge.yml` start only on a dispatch from `pr merge`. It keeps the judge on the default branch's rules and the release bot's token, so the bot's merge starts the release and CI. Delete `auto-merge-sweep.yml`, `babysit.yml`, `babysit-sweep.yml`, `grade-verdicts.yml`, `ci-explain.yml` and the scripts that only they ran.
5. Update the deliver and babysit-pr skills, the pull request reference, the command index, the rollback page, the capability registry, the risk tiers and CODEOWNERS.

## Acceptance criteria

- No event or schedule starts a merge. Only `pr merge` dispatches `auto-merge.yml`.
- `pr merge` refuses a PR that the judge holds, and prints the reasons.
- `pr merge` reports a red `main` after its merge and starts the revert.
- `bun run validate` passes.
