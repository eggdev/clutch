# CL-582: Leave the generated snapshot of a migration out of the PR size count

## Goal

The size limit of a pull request counts the lines that a person or an agent wrote, not the snapshot that the migration generator writes.

## Context

`tools/check-scope.ts` stops a pull request that changes more than `pr_size.max` lines, 1,000 by default. It leaves out the tracker, lockfiles and screenshot baselines, because no one writes them. The migration generator writes a `snapshot.json` next to each `migration.sql`, and that file counted. On 2026-11-20, PR #308 added one table and failed the check at 1,014 lines, of which 212 were the snapshot. The owner agreed on 2026-11-20 to leave these snapshots out.

## Steps

1. Branch `clutch/cl-582-scope-snapshots`.
2. Write the failing test first, in `tools/check-scope.test.ts`.
3. Add `**/migrations/**/snapshot.json` to the files that `check-scope` always leaves out, and to the files that `clutch labels` leaves out of the size label, so both count the same.

## Files

- `tools/check-scope.ts`, `tools/check-scope.test.ts`
- `apps/cli/src/labels/compute.ts`, `apps/cli/src/labels/compute.test.ts`
- `docs/contributing/harness-engineering.md`, `docs/contributing/capabilities/pr-size-limits.md`

## Acceptance criteria

- The snapshot of a migration does not count toward the limit.
- The SQL of a migration still counts.
