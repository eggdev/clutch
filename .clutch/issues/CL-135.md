# CL-135: Run Semgrep where code scanning is not available

## Goal

Every project made from Clutch gets static analysis and one stable required check, `sast`, whether its repository is public or private.

## Context

- Code scanning on a private repository needs GitHub Code Security, sold to organizations at about $30 per active committer per month. Brendan decided on 2026-10-30 not to pay for it, and still wants static analysis on private repositories.
- CodeQL's license allows free use only on open-source code, so a private repository without Code Security must not run the CodeQL CLI either.
- Semgrep Community Edition is LGPL, needs no account, and runs from a container image pinned by digest.
- CL-308 makes the SAST check required. One stable job name lets one ruleset file fit every repository.

## Steps

1. Replace `codeql.yml` with `sast.yml`. An `engine` job probes `GET /repos/{repo}/code-scanning/alerts`: a 403 means no Code Security, so Semgrep runs; otherwise CodeQL runs as before. A `sast` job passes only when the picked engine passed. A `workflow_dispatch` input forces an engine.
2. Semgrep runs `semgrep scan --config p/default --error --metrics off` from `semgrep/semgrep` pinned by digest. Turn off, with a reason, each rule that is wrong for the whole repository.
3. `check-suppressions` accepts `nosemgrep` only as `nosemgrep: rule-id -- reason`, and also scans scripts and workflows.
4. `codeql_sast` detection counts a workflow that runs `semgrep scan`.
5. Add `sast: auto | codeql | semgrep` to `clutch.yaml`, default `auto`. `sast.yml` reads it: `codeql` fails loudly where code scanning takes no results, and `semgrep` runs Semgrep on a public repository too. Clutch sets `auto`, which runs CodeQL here.
6. `clutch doctor` prints the chosen path. With `--remote` it probes code scanning, and `--check` fails `codeql` on a private repository without Code Security.
7. The kickoff setup checklist asks the SAST question with its trade-off, and records the answer in `clutch.yaml`.
8. Document every mode in `docs/contributing/capabilities/codeql-sast.md`.

## Files

- `.github/workflows/sast.yml` (was `codeql.yml`)

- `apps/cli/src/clutch-config/schema.ts`, `apps/cli/src/doctor/{sast,remote}.ts`, `apps/cli/src/doctor-command.ts` and their tests
- `clutch.yaml`, `.agents/skills/kickoff/references/setup-checklist.md`, `apps/cli/README.md`
- `docs/contributing/capabilities/registry.yaml`, `codeql-sast.md`

## Acceptance criteria

- On this public repository, `sast` runs CodeQL and passes.
- With the engine forced to `semgrep`, `sast` runs Semgrep, fails on a finding and passes without one.
- `clutch doctor --check` passes with `codeql_sast` adopted.
- `clutch doctor --remote` prints `SAST: auto -> codeql (public repository)` here.
