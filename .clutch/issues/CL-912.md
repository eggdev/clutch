# CL-912: Move bun run pr into clutch pr, so the binary carries it

## Goal

Projects run the pull request commands as `clutch pr <command>`, from the release binary, like every other workflow command.

## Context

CL-902 (Brendan, 2026-11-01): Clutch is the primary driver of the workflow. `bun run pr` lives in `tools/github/pr.ts`, which a project gets only through `clutch sync`. A command in the binary reaches every project on release, with no sync decision, as CL-201 decided for `clutch worktree`.

## Steps

1. Add `clutch pr` to `apps/cli`, with the commands of `tools/github/pr.ts`.
2. Keep `bun run pr` as a thin wrapper for one release, then retire it.

## Trigger

When a project has to sync to get a `pr` fix, or when CL-913 needs `pr` inside the binary.
