# CL-604: Run the Clutch doctor workflow in Neighborhood CI

## Goal

Neighborhood CI fails on a Clutch regression.

## Steps

1. Add a `clutch` job to Neighborhood `ci.yml` that calls the reusable workflow. The caller looks like this:

```yaml
jobs:
  clutch:
    uses: eggdev/clutch/.github/workflows/clutch-doctor.yml@main
```

In `ci.yml`, add only the `clutch` entry under the existing `jobs:` key. The workflow checks out the latest Clutch release (CL-028).

2. Open the PR. Making the job required is Brendan's ruleset decision. Ask him in the thread.

## Acceptance criteria

- The job is green on the PR.

## Verify

```bash
gh pr checks <PR> --repo eggdev/neighborhood
```

## Notes

- Verify first: the check name shown by `gh pr checks` after the first run was not checked from this repository.
