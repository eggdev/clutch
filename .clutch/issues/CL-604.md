# CL-604: Run the Clutch doctor workflow in Neighborhood CI

## Goal

Neighborhood CI fails on a Clutch regression.

## Steps

1. Add a `clutch` job to Neighborhood `ci.yml` that calls `eggdev/clutch/.github/workflows/clutch-doctor.yml@<pinned sha>`.
2. Open the PR. Making the job required is a ruleset change, so ask Brendan.
