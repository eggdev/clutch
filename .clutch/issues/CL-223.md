# CL-223: Keep an owner finding until the diff removes its cause

## Goal

Agent review carries an `owner` finding from an earlier head to each new head until the diff removes its cause. A silent drop on a later head still holds the PR. On Neighborhood #41 the earlier head got an `owner` finding (native fatal crashes would be lost), the final head got none although the cause was still in the diff, and auto-merge merged it.

## Context

- Agent review runs again on each push with no memory of the earlier heads, so a finding can vanish on a re-run.
- `Count every owner finding` reads only the current head's inline comments. Nothing reads the earlier heads.

## Steps

1. In `.github/workflows/agent-review.yml`, add "Collect earlier owner findings" before the review. It lists the bot's `owner` review comments on commits other than the head and writes them to `$RUNNER_TEMP/prior-owner.md`, or `None.`.
2. In the review prompt, check each earlier owner finding against the full diff. Raise it again while its cause is in the diff. Drop it only with a "Resolved owner findings" entry in the summary that names the diff line that resolves it.
3. In "Count every owner finding", print the number of earlier owner findings. Without a "Resolved owner findings" section in this run's summary, raise an "Owner review needed" warning for each one.
4. Document the carry-over in `docs/contributing/review.md`.

## Files

- `.github/workflows/agent-review.yml`
- `docs/contributing/review.md`

## Acceptance criteria

- "Collect earlier owner findings" prints the count of findings it lists, and fails the job when the comments cannot be listed.
- "Count every owner finding" prints the earlier-finding count, and raises "Owner review needed" for each one when the summary has no "Resolved owner findings" section.
- Permissions, environment, secrets, triggers and pinned SHAs are unchanged.
- `mise exec -- bun run validate` passes.

## Verify

```bash
mise exec -- bun run validate
gh run view <run id> --log | grep -E "Collect earlier owner findings|Count every owner finding" -A4
```
