# CL-916: Ask the owner before each agent change to a rule, also for shell edits and the hard invariants

## Goal

In a session, an agent changes a rule only when the owner asks for the change or allows it, in each way that an agent can edit a file.

## Context

The owner stated the rule on 2026-11-13, and decision record 0006 holds it: in a session, a change to a rule comes from the owner, or the owner allows the session to make it. Clutch has this guard for one path. `tools/agent-hooks/guard-guardrails.ts` runs before an edit to a file that `tools/guardrail-files.json` lists. Claude Code shows the owner a permission prompt. Codex refuses the edit and tells the agent to ask. Three gaps remain.

- `.claude/settings.json` runs the hook for `Edit`, `MultiEdit`, `Write` and `NotebookEdit` only. A shell command that writes the file gets past it.
- `docs/contributing/project-intent.md` is under `exempt`, so the hook does not ask before a change to a hard invariant.
- The merge gate adds no hold. A session with no hook can change a rule and merge it. Decision record 0005 accepts that, and the weekly digest lists each such change.

The owner decided that this guard comes after the P5 work, so this issue is in `later`. It adds no review of a pull request. The owner agrees in the session, or in the T3 thread of a lane.

## Steps

1. Branch `clutch/cl-916-rule-change-guard`.
2. Run the guard for a shell command that writes a guardrail file, for each agent.
3. Cover the hard invariants of `project-intent.md` with the guard, and correct its `exempt` entry.
4. Decide with the owner whether the merge gate needs proof that the owner agreed, such as a line in the issue.
5. State the rule in `docs/principles/proof-gates-code.md`.

## Files

- `tools/agent-hooks/guard-guardrails.ts`, `.claude/settings.json`, `.codex/hooks.json`
- `tools/guardrail-files.json`
- `docs/principles/proof-gates-code.md`, `docs/contributing/harness-engineering.md`

## Acceptance criteria

- A shell command that writes a guardrail file asks the owner first, in Claude Code and in Codex.
- A change to a hard invariant asks the owner first.
- An edit that the owner asked for or allowed goes through.
