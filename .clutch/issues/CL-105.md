# CL-105: Audit CI credentials and adopt OIDC or waive it

## Goal

Each long-lived CI secret either moves to OIDC or has a recorded waiver.

## Steps

1. Branch `clutch/cl-105-oidc`.
2. List secrets used in workflows: `rg -n 'secrets\.' .github/workflows`. Expect the Nx cache token, the agent-review key and the Cloudflare token in `nx-cache.yml`.
3. For each one, record in the PR body: the provider, whether it supports GitHub OIDC, and the scope.
4. Cloudflare Wrangler has no GitHub OIDC trust. Waive `oidc_ci` with that reason and `until` 6 months out. Do not change any secret, because credential changes are a human gate.
5. Write `docs/contributing/setup/ci-credentials.md` describing each secret's scope. Follow the doc rules.

## Acceptance criteria

- `clutch.yaml` has an `oidc_ci` decision with a reason.
- The doc lists every `secrets.*` name found by `rg`.

## Verify

```bash
rg -o 'secrets\.[A-Z_]+' -N .github/workflows | sort -u
mise exec -- bun run validate
```
