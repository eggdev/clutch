# CL-602: Adopt Clutch in Neighborhood with clutch init --adopt

## Goal

Neighborhood has `clutch.yaml`, a lineage record and a doctor baseline.

## Steps

1. Clone or update `~/src/neighborhood` (confirm the machine and path in CL-601). Branch `clutch/cl-602-adopt` from the base recorded in CL-601.
2. Pull the Clutch tags first: `git -C ~/src/clutch pull --tags`. Then from the Clutch checkout: `bun ~/src/clutch/apps/cli/src/main.ts init --root ~/src/neighborhood --mode sync --adopt --yes`.
3. Init does not read `.review/tooling.json`. Leave that file alone here. The first sync reads it (CL-603).
4. Add the mise entry to Neighborhood `mise.toml`: `"github:eggdev/clutch" = { version = "latest", minimum_release_age = "0s" }`. Then `mise exec -- bun run clutch` works in the repo.
5. Review each core gap waiver. Replace "Decide during adoption." with a reason and an issue in Neighborhood's own `.clutch/issues/`.
6. Run Neighborhood's `mise exec -- bun run validate` and open a PR in `eggdev/neighborhood`.

## Acceptance criteria

- `clutch doctor --check --root ~/src/neighborhood` exits 0.
- `rg -n "Decide during adoption" clutch.yaml` finds nothing.

## Verify

```bash
bun ~/src/clutch/apps/cli/src/main.ts doctor --check --root ~/src/neighborhood
rg -n "Decide during adoption" ~/src/neighborhood/clutch.yaml
```
