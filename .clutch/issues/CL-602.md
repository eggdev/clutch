# CL-602: Adopt Clutch in Neighborhood with clutch init --adopt

## Goal

Neighborhood has `clutch.yaml`, a lineage record and a doctor baseline.

## Steps

1. Clone or update `~/src/neighborhood`. Branch `clutch/cl-602-adopt` from the base recorded in CL-601.
2. From the Clutch checkout: `bun ~/src/clutch/apps/cli/src/main.ts init --root ~/src/neighborhood --mode sync --adopt`.
3. Neighborhood has `.review/tooling.json`. Confirm that init reads it into `.clutch/lineage.json`.
4. Review each core gap waiver. Replace "Decide during adoption." with a reason and an issue in Neighborhood's own `.clutch/issues/`.
5. Run Neighborhood's `bun run validate` and open a PR in `eggdev/neighborhood`.

## Acceptance criteria

- `clutch doctor --check --root ~/src/neighborhood` exits 0.

## Verify

```bash
bun ~/src/clutch/apps/cli/src/main.ts doctor --check --root ~/src/neighborhood
```
