# CL-226: Edit issue bodies through REST in grade-verdicts

## Goal

`grade-verdicts.ts` edits the weekly calibration issue's body through the REST API, not `gh issue edit`, which fails on Projects (classic) and does not apply the change.

## Context

Found in the Neighborhood revert drill (#48): `gh pr edit` fails with a GraphQL "Projects (classic) is being deprecated" error and does not apply the change. `gh issue edit` uses the same GraphQL path. PR #168 moves the same fix for `auto-revert.ts`, `upsert-recap-block.ts` and `clutch-sync.yml`.

## Steps

1. Replace the `gh issue edit` in `calibrate` with `gh api -X PATCH repos/{owner}/{repo}/issues/<n>`, passing the body with `-F body=@file` and the title with `-f title=`.
2. Update the fake-Run tests to expect the REST call.

## Files

- `tools/github/grade-verdicts.ts`
- `tools/github/grade-verdicts.test.ts`

## Acceptance criteria

- No `gh issue edit` remains in `tools/` outside #168's files.
- The calibration tests pass and expect the PATCH call.

## Verify

`mise exec -- bun test tools/github/grade-verdicts.test.ts`, then `mise exec -- bun run validate`.
