# CL-448: Warm PGlite before the first access test

## Goal

The access tests never time out on PGlite's first start.

## Context

- `packages/access/service/access.test.ts` "every actor loads its organization and user groups at once, and each of its spaces on request" timed out at 5138 ms in CI on eggdev/clutch#228 (run 42336238770) and failed again on #230 (run 42341900353), on commits that do not touch it.
- Locally it takes 1.2 s, while the next tests in the file take 0.13 s each. The first test pays the one-time start of PGlite, which loads its WASM. On a busy runner, where validate runs many tasks at once, that start passes bun's 5 s test timeout.
- Both runs are in `.clutch/friction.jsonl` as `flake`.

## Steps

1. Branch `clutch/cl-448-warm-pglite`.
2. Start the access test database once in a `beforeAll` with its own 30 s limit, so the first test measures only its own work.

## Files

- `packages/access/service/access.test.ts`

## Acceptance criteria

- The first access test takes about as long as the others.
- `bun run validate` passes.

## Verify

`mise exec -- bun test packages/access`, and its time for each test.
