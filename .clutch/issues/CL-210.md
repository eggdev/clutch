# CL-210: Read the owner findings in pr status

## Goal

`pr status` reads every agent review summary, and it treats an `owner`
finding as waiting for the owner.

## Context

On #148, agent review wrote ``No `blocking` findings.`` `pr status` kept the
code marks, matched none of its patterns, and printed "blocking count is
unreadable", so the PR never showed as ready. CL-208 added `owner` findings,
which `pr status` did not count.

## Steps

1. Strip code marks before matching, and read "No blocking" as 0.
2. Count each summary bullet that starts with `owner`.
3. A PR with an `owner` finding is ready only when the owner approved it,
   and `pr merge` refuses it until then. A written count wins over a "no
   blocking" phrase.

## Files

- `tools/github/status.ts`, `tools/github/merge.ts`, `tools/github/lifecycle.test.ts`
- `.agents/skills/deliver/references/pull-requests.md`

## Acceptance criteria

- The #148 summary reads as 0 blocking and 5 owner.
- An owner finding keeps a green PR from ready, and `pr merge` refuses it,
  until it is approved.
