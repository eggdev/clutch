# CL-437: Merge the labels and risk workflows and drop the SAST cron

## Goal

One workflow labels each pull request with its kind, area, size and risk tier. SAST runs on pull requests and pushes to `main` only.

## Context

Brendan, 2026-11-06: clean up and consolidate the GitHub Actions. `labels.yml` and `risk.yml` both label a PR on the same events. The weekly SAST run is a cron that no task owns; each push to `main` already runs it.

## Steps

1. Merge `risk.yml` into `labels.yml`. Keep the risk tier on the base branch's CLI and rules.
2. Remove the `schedule` trigger from `sast.yml`.
3. Update the docs and the capability registry.

## Acceptance criteria

- One workflow sets `kind/`, `area/`, `size/` and `risk/` labels.
- `sast.yml` has no `schedule` trigger.
- `bun run validate` passes.

## Verify

`mise exec -- bun run validate`.
