# CL-528: Add Exact as a client profile over the contract

## Goal

A project can pick Exact as a client profile, with the object pool as its data module.

## Context

Exact compiles one declared view to web, Apple, Linux, Windows and Android hosts, and its data module can import pure JavaScript packages, Effect among them. Its contract ends where the data module calls the network, which is where Clutch's contract begins. Exact has no releases yet and changes each day, so this waits until it can run in production. The manifest in `contract.json` is what an Exact data module would bind to.

## Steps

1. Wait for an Exact release that the owner accepts for production.
2. Generate the Exact `Sources` of an app from the manifest: a resource for each load function and a send for each command.
3. Run the object pool inside the data module, and feed each resource from it.
4. Prove it on one app with its own server before the template offers the profile.
