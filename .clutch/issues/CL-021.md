# CL-021: Close out P0: map entry, README and the P0 done report

## Goal

Make Clutch discoverable from the 20-line `AGENTS.md` and report the end of P0.

## Steps

1. Branch `clutch/cl-021-p0-close`.
2. `AGENTS.md` is capped at 20 lines by `check-file-size`. Replace or merge one line so the map includes: "`.clutch/issues/` is the task tracker; `bun run clutch issues next` names the next task." Keep 20 lines or fewer.
3. Update the root `README.md` quick start with `bun run clutch doctor`.
4. Run `clutch doctor --json` and paste the summary into the PR body.
5. After merge, set every P0 issue to `done` (`clutch issues set`). Then report in the PR: "P0 complete: <summary counts>. Next: P1 (CL-101) and RN/RB repo track."

## Files

- edit `AGENTS.md`, `README.md`

## Acceptance criteria

- `AGENTS.md` has 20 lines or fewer.
- `clutch issues` shows every P0 issue done except gated ones that are still pending.

## Verify

```bash
wc -l AGENTS.md
mise exec -- bun run clutch issues --json | jq '[.issues[] | select(.phase=="P0" and .status!="done")]'
```
