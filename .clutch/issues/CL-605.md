# CL-605: Propose Neighborhood strengths for upstream into Clutch

## Goal

Neighborhood is ahead of the template in some areas.

- The Bugbot gate (`one-way-door.yml`).
- Preview environments (`ci.yml` preview job, `preview-cleanup.yml`).
- CD on green main (`deploy.yml`).
- `monitor-ci`.
- `tools/validate.ts --affected`.

## Steps

1. Check overlaps first. `--affected` against CL-303 (`changed_scope_check`). The review tooling against `ai_review_blocking`. The failure explainer against CL-305.
2. For each item, write a short proposal in this issue: what it is, which capability it serves, and whether it is generic.
3. Open one `.clutch/issues` entry in Clutch per accepted item. New Clutch issues take the next free id in their phase range (CL-1xx to CL-5xx). Link each new id here. Brendan decides which to accept. Ask him in the thread.
