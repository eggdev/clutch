# CL-303: Run CI on the affected scope for PRs

## Goal

PR CI runs `nx affected` against the PR base. Main runs everything.

## Steps

1. Branch `clutch/cl-303-affected-ci`.
2. In `ci.yml`, compute the base and head SHAs for PRs: the merge base with `origin/main`, or use `nrwl/nx-set-shas` pinned by SHA (Neighborhood uses it). Run `nx affected -t <same targets as validate>`. Keep `checks` always on, because root checks are global.
3. On `push` to main and on `merge_group`, keep `bun run validate`.
4. Adopt `changed_scope_check`.

## Acceptance criteria

- A docs-only PR runs only `checks`.
- A main push runs the full validate.

## Verify

```bash
gh run list --workflow ci.yml --limit 3
```
