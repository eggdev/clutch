# CL-541: Add a lint rule that stops a component from reading the viewport width

## Goal

A component that reads the viewport width fails lint.

## Context

Mobile first says a component responds to its container and never reads the viewport width. Only the app shell uses viewport breakpoints. No check holds the principle, so only review stops it (CL-531).

## Steps

1. Branch `clutch/cl-541-no-viewport-reads`.
2. Add a rule to `tools/lint/` that fails `window.innerWidth`, `matchMedia` and `useWindowDimensions` outside the app shell.
3. Turn it on in `oxlint.config.ts`, with tests.
4. In `docs/principles/index.md`, replace `Review only` with the new rule's name, and delete the rule from `docs/contributing/review.md` in the same PR.

## Files

- `tools/lint/`, `oxlint.config.ts`
- `docs/principles/index.md`, `docs/contributing/review.md`

## Acceptance criteria

- A viewport read in a component fails lint, and one in the app shell passes.
- The principle's `Held by` cell names the new rule.
