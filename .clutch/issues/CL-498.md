# CL-498: Drive the device that the caller opened through agent-device

## Goal

The template has one device host, `pool`. It drives the device that the caller opened, through the `agent-device` command that the `AGENT_DEVICE` environment variable names. The Maestro command line tool and Java are gone.

## Context

The owner's machines share one pool of iOS simulators and Android emulators. An agent leases a device with T3 Code's `device_open`, which returns the path of an `agent-device` command that is bound to that device. Neighborhood proved the contract in its branch `chore/native-checks-on-device-pool`: a script takes that path in `AGENT_DEVICE`, and never opens or closes a device. The pool gives each lease its own device, so a pool device needs no machine-wide lock.

The hosts `none`, `ci` and `local` each drive a device that is booted on the machine that runs the command, with the Maestro command line tool. The pool replaces all three. A device on the owner's own Mac also comes through `device_open`, so no host needs `xcrun simctl` or `adb`.

## Steps

1. In `tools/native/device-host.ts`, read `AGENT_DEVICE`. With no variable, or with the command of a closed device, refuse and name the fix.
2. Add the `pool` host: `install` runs `agent-device install <app>`, and `runFlow` runs `agent-device replay <flow> --maestro`. It is the only host, so `DEVICE_HOST` goes.
3. Remove the hosts `none`, `ci` and `local`, the machine-wide lock, `tools/native/maestro.ts` and the `checkFlow` call.
4. `build` of the `pool` host refuses until CL-499 adds the build machine. Remove `native:build --install` until then.
5. Rewrite the device parts of `docs/contributing/setup/native.md` and `docs/contributing/end-to-end-testing.md`.

## Acceptance criteria

- C1: With no `AGENT_DEVICE`, each device call refuses with one message that names `device_list`, `device_open` and the variable.
- C2: With `AGENT_DEVICE` set to a fake command, `install` and `runFlow` call it with `install <app>` and `replay <flow> --maestro`. A test holds this.
- C3: The repository has no call of the `maestro` command, no `JAVA_HOME` lookup, no `xcrun simctl`, no `adb` and no device lock.
- C4: `mise exec -- bun run journey --native ios` runs each compiled flow through the host on the opened device.
