# CL-606: Turn on design-system-only and gallery screenshots in Neighborhood

## Goal

Neighborhood lints raw elements with `repo-components/design-system-only`, and its gallery has screenshot baselines.

## Context

- CL-406 adds the rule. Neighborhood edited its `oxlint.config.ts`, so a sync makes that file a keep-or-take decision. Keep it, and add the plugin and the rule by hand. At `fe533053` the rule flags 7 call sites in 7 files: 5 `Pressable` and 2 `TextInput`. Fix them; they are too few to ratchet.
- CL-412 adds `snap`. Neighborhood has no web journey yet. A gallery journey opens `/gallery/<group>` for each group and snaps it.

## Steps

1. Sync to the release that has CL-406 and CL-412.
2. Add the plugin and the rule to `oxlint.config.ts`, and fix the 7 call sites.
3. Set `journeys.webApp`, and add a gallery journey that snaps each group. Mask the animated parts (marquee, typing indicator, live activity).
4. Generate the baselines in CI with `visual pull`.

## Acceptance criteria

- Lint passes with the rule on.
- The gallery journey passes in CI, with 4 baselines for each group.

```bash
mise exec -- bun run validate
mise exec -- bun run journey --all
```
