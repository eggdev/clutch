# CL-217: Make agent review count every owner finding and read large diffs

## Goal

The gate counts every `owner` finding the review posted, not only the ones in the structured answer, and the agent reviews the whole diff on a large PR. The owner-finding gap on PR #153 made the gate fail open, and a PR of 300+ files was reviewed in slices.

## Context

- The review's structured `owner` array feeds the "Owner review needed" annotations that auto-merge reads. On PR #153 the review comment listed 3 owner findings and the structured output had 2, so auto-merge saw 2.
- `gh pr diff` and the files API hit their limits on a large PR, so each run reviewed a different slice and raised new findings (Neighborhood #27, 300+ files).

## Steps

1. In `.github/workflows/agent-review.yml`, check out the PR head with `fetch-depth: 0` and write the full diff with git into `$RUNNER_TEMP/pr.diff`. The prompt reads that file and uses `gh pr diff` only when it is missing.
2. Add "Count every owner finding" after the blocking-finding step. It counts the inline `owner` comments on the head commit and the `owner` items in the structured output, prints both, and raises one "Owner review needed" warning per inline owner comment when the inline count is larger. It never fails the job.
3. Document both in `docs/contributing/review.md`.

## Files

- `.github/workflows/agent-review.yml`
- `docs/contributing/review.md`

## Acceptance criteria

- The agent-review run's "Write the full diff" step prints the file and line counts of the PR.
- The "Count every owner finding" step prints both owner counts, and raises an "Owner review needed" warning for each inline owner comment when the inline count is larger.
- Permissions, environment, secrets, triggers and pinned SHAs are unchanged.
- `mise exec -- bun run validate` passes.

## Verify

```bash
mise exec -- bun run validate
gh run view <run id> --log | grep -E "Write the full diff|Count every owner finding" -A4
```
