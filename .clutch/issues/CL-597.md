# CL-597: Close the review findings of the device pool stack

## Goal

Each defect that the review of CL-497 to CL-595 found is fixed, with a test.

## Context

A review of the whole stack on 2026-11-21 found 2 blocking defects and 9 smaller ones. None changes the proof on the pool device. They touch files of several pull requests of the stack, so one pull request on top fixes them.

## Steps

1. A top-level `assertTrue` step runs on this machine. Before, the runner sent the device the text `true` or `false`, so a failed tool call depended on how `agent-device` reads that text.
2. A device step that still holds `${` after the script host resolved it is refused.
3. The hook messages no longer say that `native:build` refuses a JavaScript-only change, and the Simulator tool refusal names only the pool.
4. The build script takes the expected fingerprint and stops before the prebuild when the head commit has another one. A second caller that loses the lock exits 75.
5. `clutch doctor` checks the build machine setting with the rule that `native:build` uses.
6. The dev server link starts its own forward unless this machine already runs one. A listener of another machine on that port is refused.
7. The probe quotes its URL, the ssh name cannot start with `-`, and each ssh call has a connect timeout and a keep-alive.
8. The reach summary no longer says that a native lane runs.

## Files

- `tools/journeys/flow-parts.ts`, `tools/journeys/native-parts.ts`, `tools/journeys/reach.ts` and their tests
- `tools/native/build-machine.ts`, `tools/native/dev-link.ts`, `tools/native/ios-simulator-build.sh` and their tests
- `tools/agent-hooks/guard-dev-servers.ts`, `tools/agent-hooks/simulator-tools.ts`
- `apps/cli/src/doctor/native-machine.ts`
- `docs/contributing/setup/native.md`, `docs/contributing/end-to-end-testing.md`

## Acceptance criteria

- C1: A tool call that the server refuses fails the journey, and the device gets no `assertTrue` step. A test holds this.
- C2: A flow step with a `${...}` that the host cannot resolve fails before the device gets it.
- C3: A build of a checkout with an uncommitted native change stops before the prebuild.
- C4: With another listener on the port of the build machine, the link refuses and names the port.
- C5: The journey `notes-sync` still passes on a pool iPhone 17.
