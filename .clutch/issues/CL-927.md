# CL-927: Remove old native builds from the build machine

## Goal

The build folder of a project on the build machine does not grow without a limit.

## Context

`tools/native/ios-simulator-build.sh` keeps one build of each native fingerprint in `artifacts/<fingerprint>/`, about 220 MB each for the template app, and package caches of about 2.5 GB in `cache/`. Nothing removes an old build. The disk of the owner's build machine is small.

## Steps

1. Remove each artifact that no build used for some weeks, at the end of a build.
2. Print the size of the project folder at the end of a build.

## Files

- `tools/native/ios-simulator-build.sh`
- `docs/contributing/setup/native.md`

## Acceptance criteria

- C1: A build removes each artifact older than the limit, and keeps the one it made.

## Verify

`mise exec -- bun test tools/native/ios-simulator-build.test.ts`
