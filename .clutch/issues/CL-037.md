# CL-037: Run the agent workflows on the cheapest model by default

## Goal

Every workflow that spends the Anthropic credential uses the cheapest model unless the project chooses another one.

## Context

The repository now has an `ANTHROPIC_API_KEY` secret, so `agent-review.yml` and `gardening.yml` do real work. Neither names a model, so the action picks its default. Brendan asked for the cheapest model while the factory is young.

## Steps

1. Pass `--model ${{ vars.CLUTCH_AGENT_MODEL || 'claude-haiku-5-5' }}` in `claude_args` of each `anthropics/claude-code-action` step.
2. Pass `github_token: ${{ github.token }}` to each action step. Without it, the action swaps an OIDC token for a Claude GitHub App token and fails when that app is not installed. The first real run on PR #49 failed that way.
3. Document the `CLUTCH_AGENT_MODEL` repository variable in `docs/contributing/review.md` and in the gardening section of `docs/contributing/harness-engineering.md`.

## Files

- `.github/workflows/agent-review.yml`
- `.github/workflows/gardening.yml`
- `docs/contributing/review.md`
- `docs/contributing/harness-engineering.md`

## Acceptance criteria

- Both workflows pass `--model` with the Haiku default and the variable override.
- The agent-review run on this PR names the Haiku model in its log.

## Verify

```sh
grep -n -- '--model' .github/workflows/*.yml
mise exec -- bun run validate
```
