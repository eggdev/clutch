# CL-102: Add the CodeQL workflow

## Goal

Static analysis on every PR and on main.

## Steps

1. Branch `clutch/cl-102-codeql`.
2. Add `.github/workflows/codeql.yml`:
   - `on: [push to main, pull_request, merge_group, schedule weekly]`
   - top-level `permissions: { contents: read }`, and job `permissions: { security-events: write, actions: read, contents: read }`
   - languages `javascript-typescript` and `actions`, plus `python` because `tools/verification/verify.py` exists
3. Use `github/codeql-action/init` and `analyze` at their current major. CL-103 pins SHAs.
4. Adopt `codeql_sast` in `clutch.yaml`, drop the waiver and raise the baseline.

## Acceptance criteria

- The CodeQL run on the PR is green.
- `check-workflows` passes.
- `clutch doctor --check` passes with `codeql_sast` adopted.

## Verify

```bash
mise exec -- bun nx run check-workflows
gh pr checks --watch
```
