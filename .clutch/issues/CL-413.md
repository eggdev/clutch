# CL-413: Review changed screenshots with an image model

## Goal

When a PR adds, changes or removes a screenshot baseline, a cheap image model compares before and after against the PR's intent and the design rules. The review blocks only on a change that is unexplained or broken. The check posts the before and after pictures to the PR.

## Context

See the design note in CL-412, step 5. The step goes in the `agent-review` job, which is required and holds the Anthropic credential. That file is in the `one-way-door` tier, so Brendan approves this PR.

## Steps

1. Add `tools/visual/review.ts`: list the changed baselines, batch the pairs, call `claude-haiku-5-5` with a structured output, post or edit one comment, and exit 1 on a block.
2. Add a step to `.github/workflows/agent-review.yml` that runs it only when a baseline changed.
3. Measure the cost on a real PR, and record it here.
4. Document it in `docs/contributing/review.md`.

## Acceptance criteria

- A PR that changes a baseline and gives the reason passes, and its comment shows before and after.
- A PR that changes a baseline with no reason fails the step.
- A PR with no baseline change makes no API call.

## Verify

```bash
mise exec -- bun test tools/visual
```
