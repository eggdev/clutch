# CL-413: Review changed screenshots with an image model

## Goal

When a PR adds, changes or removes a screenshot baseline, a cheap image model compares before and after against the PR's intent and the design rules. The review blocks only on a change that is unexplained or broken. The check posts the before and after pictures to the PR.

## Context

See the design note in CL-412, step 5. The step goes in the `agent-review` job, which is required and holds the Anthropic credential. That file is in the `one-way-door` tier, so Brendan approves this PR.

## Steps

1. Add `tools/journeys/visual-review.ts`: list the changed baselines, batch the pairs, call `claude-haiku-5-5` with a structured output, post or edit one comment, and exit 1 on a block.
2. Add a step to `.github/workflows/agent-review.yml` that runs it only when a baseline changed.
3. Let `snap` and `check-flaky-tests` read quarantined snap names from `tools/flaky-tests.json` (design note in CL-412, flaky diffs).
4. Measure the cost on a real PR, and record it here.
5. Document it in `docs/contributing/review.md`.

## Acceptance criteria

- A PR that changes a baseline and gives the reason passes, and its comment shows before and after.
- A PR that changes a baseline with no reason fails the step.
- A PR with no baseline change makes no API call.

## Verify

```bash
mise exec -- bun test tools/journeys
```

## Notes

Measured on 2026-11-03 with `claude -p --model claude-haiku-5-5`, the same prompt and the same JSON schema. 2 pairs: one identical pair, and one where the home page became the notes screen.

| PR body                                        | Verdicts                          | Cost    | Turns | Tokens (cache write, cache read, output) |
| ---------------------------------------------- | --------------------------------- | ------- | ----- | ---------------------------------------- |
| "The home page now shows the notes screen ..." | both explained, none broken       | $0.0083 | 7     | 33,610, 56,049, 1,789                    |
| "No user-visible change."                      | home unexplained, notes explained | $0.0059 | 7     | 22,015, 67,646, 1,329                    |

Most of the cost is the Claude Code system prompt, which is cached. Each extra pair adds 2 image reads. Clutch's secret is `CLAUDE_CODE_OAUTH_TOKEN`, so the step runs through `claude-code-action`, not a direct Messages API call. A direct call would need an `ANTHROPIC_API_KEY`.
