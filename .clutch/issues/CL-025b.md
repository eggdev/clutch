# CL-025b: Install the clutch binary with mise in every project

## Goal

`mise install` puts the `clutch` release binary on the PATH in Clutch and in each project, so `mise exec -- bun run clutch issues` works in a project.

## Context

- CL-025 makes each release carry `clutch-<os>-<arch>.tar.gz` and adds `tools/clutch.ts`, which runs the binary in a project.
- v0.1.0 has no binaries. When `mise.toml` names `github:eggdev/clutch` before a release has them, `mise install` fails in every CI job. So this lands after the first release that CL-025 makes.
- mise hides a release younger than 24 hours by default. Clutch releases on each merge, so the entry sets `minimum_release_age = "0s"` for its own tool, like `minimumReleaseAgeExcludes` in Bun.

## Steps

1. Check that the latest release has the four archives.
2. Add `"github:eggdev/clutch" = { version = "latest", minimum_release_age = "0s" }` to `mise.toml`, with a comment.
3. Run `mise install` and `mise exec -- clutch issues` in a scratch project with `tools/clutch.ts`.

## Acceptance criteria

- In a project made by `clutch install`, `mise install` then `mise exec -- bun run clutch issues --write` runs.
- CI and validate pass.
