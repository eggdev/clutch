# CL-455: Hold a weaker journey deterministically, and make model findings advisory

## Goal

The owner is asked when a journey or budget gets weaker, as code decides it. No model finding holds a merge.

## Context

Council review, 2026-11-08: agent review's model findings held PRs. The owner wants deterministic checks throughout. This takes steps 3 and 4 of CL-441 for the merge decision.

## Steps

1. Add `tools/github/weaker-journeys.ts`. Compare each changed journey and `budgets:` with the merge base.
2. Make the judge hold a weaker journey until the owner approves the head.
3. Stop owner and blocking findings from holding the judge, `pr status` and `pr merge`.
4. Make the agent-review job report findings without failing on them.

## Files

- `tools/github/weaker-journeys.ts`, `tools/github/auto-merge.ts`, `tools/github/auto-merge-rules.ts`, `tools/github/merge.ts`, `tools/github/status.ts`, `.github/workflows/agent-review.yml`

## Acceptance criteria

- A removed outcome, a changed expected result, a removed assertion, a deleted journey and a raised budget hold the PR.
- A renamed button merges.
- A PR with only model findings merges.
- `bun run validate` passes.

## Verify

`mise exec -- bun run validate`, and `tools/github/weaker-journeys.test.ts`.
