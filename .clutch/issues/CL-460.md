# CL-460: Replace the design stop with a hand-test marker and a scope limit

## Goal

An agent builds its pick of a new screen, the owner hand tests after deploy, and each PR has a defined size limit.

## Context

System review, 2026-11-08: a design proposal stopped the owner before each new visible feature, `Hand test:` was not parsed, and PR size only warned.

## Steps

1. Parse an optional `hand_test` key in issue frontmatter.
2. Add `tools/check-scope.ts`: a PR limit of `pr_size.max` lines, and a stated `hand_test` for a new screen.
3. Make the design proposal optional in the deliver skill.

## Files

- `tools/check-scope.ts`, `apps/cli/src/issues/parse.ts`, `apps/cli/src/clutch-config/schema.ts`, `clutch.yaml`, `.agents/skills/deliver/`

## Acceptance criteria

- A PR over the limit fails, and excluded files do not count.
- A PR that adds a screen fails until a changed issue states `hand_test`.
- `bun run validate` passes.

## Verify

`mise exec -- bun run validate`, and `tools/check-scope.test.ts`.
