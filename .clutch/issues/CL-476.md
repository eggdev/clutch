# CL-476: Settle when a pull request is ready for the server to merge

## Goal

One written rule says when a pull request is ready for the server to merge. `pr open` follows that rule.

## Context

- `pr open` marks the pull request ready for review in `tools/github/pr.ts`.
- `.agents/skills/deliver/references/pull-requests.md` says "Never open a draft" in one place.
- The same file says "A session that is still working keeps its PR a draft" in another place.
- `agent-review` is not a required check.
- `.github/workflows/auto-merge.yml` judges a `clutch/` pull request when CI completes.
- So the server can merge before agent review posts and before any babysit round.

## Steps

1. Branch `clutch/cl-476-ready-rule`.
2. Find out first: what the owner wants for a pull request that has no agent review yet.
3. Write the rule once in `.agents/skills/deliver/references/pull-requests.md`. Remove the other sentence.
4. Change `pr open` in `tools/github/pr.ts` so it follows the rule. Find out first: whether `pr open` already has a draft option.
5. Change the tests with the behaviour.

## Files

- `.agents/skills/deliver/references/pull-requests.md`
- `tools/github/pr.ts`
- `.github/workflows/auto-merge.yml`

## Acceptance criteria

- One sentence in the docs says when a pull request becomes ready.
- `pr open` does what that sentence says.
- No page says both "never open a draft" and "keeps its PR a draft".
