# CL-578: Save only the records that changed, from one writer tab

## Goal

One delta writes only the records that it changed, with the sync position, in one database transaction. Only one tab writes the confirmed records, so two tabs never mix two states.

## Context

CL-575 moved the local database into rows, and the PR size limit split it. After CL-575, each save of a tab replaces every confirmed record, as the old layout did, and each tab writes them. Two tabs can hold different loaded groups and positions, so two tabs that each write rows mix two states. Linear writes only the changed rows, with the sync position in the same database transaction.

## Steps

1. Branch `clutch/cl-578-changed-rows-one-writer`, stacked on CL-575.
2. The pool tracks the keys of the confirmed records that changed, and gives them to the save with the records that were deleted.
3. A save replaces every record only after the pool drops its confirmed records, after a failed save, and when a tab becomes the writer.
4. On the web, the tab that holds the Web Lock of the database name writes the confirmed records and the position. The next tab takes over when it closes, and writes its whole state once.
5. The first save after the start deletes the rows of saved commands that this build refused.
