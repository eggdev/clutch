# CL-104: Add Renovate and a minimum release age for dependencies

## Goal

Updates arrive as small PRs, and no package version younger than 3 days installs.

## Steps

1. Branch `clutch/cl-104-renovate`.
2. `bunfig.toml`: add `[install] minimumReleaseAge = 259200` (3 days, in seconds). Confirm that bun 1.4.2 supports the key: `mise exec -- bun install --dry-run` must succeed. `bunfig.toml` is a guardrail file.
3. Add `renovate.json`:
   - extend `config:recommended`
   - `minimumReleaseAge: "3 days"`
   - `rangeStrategy: pin`
   - group Nx, oxlint and oxfmt packages
   - set `github-actions` digests to pinned
   - a weekly schedule
   - `prConcurrentLimit: 3`
   - labels `dependencies`
4. Installing the Renovate GitHub app is a repo setting. Add it to the CL-106 checklist.
5. Adopt `dep_min_age` and `dep_automation` (the latter as `waived` with `issue: CL-106` until the app runs).

## Acceptance criteria

- `bun install --frozen-lockfile` passes.
- `npx --yes --package renovate -- renovate-config-validator` passes.

## Verify

```bash
mise exec -- bun install --frozen-lockfile
npx --yes --package renovate -- renovate-config-validator renovate.json
```
