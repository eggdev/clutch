# CL-497: Remove the GitHub Actions native jobs

## Goal

No GitHub Actions job builds a native app or runs a native journey. A native journey runs from an agent session on a device of the shared pool.

## Context

The owner decided on 2026-11-21 that the template uses the shared device pool by default. GitHub Actions is off for the owner's repositories. The `native-ios` job needs a GitHub macOS runner, and the `native-android` job is a placeholder that fails. The local CI service runs jobs in Linux containers, so it can run neither job. CL-596 adds a native check that local CI can run.

## Steps

1. Remove the `native-ios` and `native-android` jobs from `.github/workflows/ci.yml`. Keep the `reach` job: CL-596 reads its output.
2. Remove the `--fresh` flag of `native:build`, which only the `native-ios` job used.
3. Say in the docs that CI runs no native journey for now.

## Files

- `.github/workflows/ci.yml`
- `tools/native/build.ts`, `tools/native/native.test.ts`
- `docs/contributing/setup/native.md`, `docs/contributing/end-to-end-testing.md`

## Acceptance criteria

- C1: `ci.yml` has no `native-ios` and no `native-android` job, and `actionlint` passes.
- C2: `native:build --fresh` prints the usage line.
- C3: No doc says that a CI job runs a native journey, sets `DEVICE_HOST` or needs `CLUTCH_IOS_LANE`.
