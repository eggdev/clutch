# CL-139: Keep Clutch-only tests out of project syncs

## Goal

A project never gets a test that can only pass in Clutch.

## Context

Neighborhood's v0.32.0 sync (eggdev/neighborhood#27) got three tests that compile `apps/cli` with `tools/release/binaries.ts`. Only Clutch has `apps/cli`, so they fail in every project. A project that deletes them gets them back on the next sync, because sync has no way to record a deleted managed file, so `clutch doctor` fails. Brendan (2026-11-02): fix it in Clutch, so Clutch's problems and a project's do not mix.

## Steps

1. List the three tests under `exclude` in `clutch.files.yaml`, with the reason.

## Files

- `clutch.files.yaml`

## Acceptance criteria

- A sync from this commit neither adds nor manages `tools/github/project.test.ts`, `tools/release/binaries.test.ts` or `tools/release/fresh-project.test.ts`.
- The three tests still run in Clutch.

## Verify

`clutch sync --check` in Neighborhood, against this commit, after deleting the three tests, plans nothing for them.
