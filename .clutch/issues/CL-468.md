# CL-468: Count the changes of a dependency in the test cache

## Goal

A cached test result of a project is not used after a change in a package that the project depends on.

## Context

- In `nx.json`, the inputs of `test` and `lint-policy-test` are `default`, which is the project's own folder. A change in `packages/sync` keeps a cached pass of the tests of `features/notes`.
- CI restores no cache, so this reaches the local `validate` and the pre-push hook only.

## Steps

1. Branch `clutch/cl-468-test-cache-inputs`.
2. Add the sources of each dependency to the inputs of `test`.
3. Measure `validate` before and after, cold and warm, and put the four times in the PR body. The budgets do not change.

## Files

- `nx.json`, `docs/contributing/setup/nx.md`

## Acceptance criteria

- After a change in `packages/sync`, `nx` runs the tests of `features/notes` again.
- `validate` stays inside its budgets.

## Verify

- `mise exec -- bun nx show project @features/notes --json`
- `mise exec -- bun run validate`
