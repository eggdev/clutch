# CL-030: Set a minimum release age in Bun and document it for every package manager

## Goal

The template installs no package version younger than three days. The capability page shows the setting for Bun, npm, pnpm and Yarn (request by Brendan, 2026-10-30).

## Steps

1. `bunfig.toml`: `minimumReleaseAge = 259200` under `[install]`.
2. Check that a fresh `bun install --frozen-lockfile` passes.
3. Fix the `dep_min_age` rule: npm's key is `min-release-age`. Add pnpm, Yarn and the Dependabot `cooldown`.
4. Rewrite the page with one table for the four package managers, from their official docs.
5. Adopt `dep_min_age` in `clutch.yaml`, and raise the baseline.

## Acceptance criteria

- `clutch doctor` reports `dep_min_age` present on the template.
- validate passes.
