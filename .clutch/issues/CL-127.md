# CL-127: Read the capability count in the binaries test

## Goal

The binaries test passes when a capability is added to the registry.

## Context

Split from CL-310. `tools/release/binaries.test.ts:124` expects `doctor --json` from the built binary to report exactly 36 capabilities. Every new capability breaks it. The file is under `tools/release/**`, which `.clutch/risk.yaml` puts in the `one-way-door` tier through the guardrail list. So it gets its own PR, and CL-310 stays `low`.

## Steps

1. Branch `clutch/cl-127-binaries-count`.
2. Read the count from `docs/contributing/capabilities/registry.yaml`, the registry that the binary carries, instead of 36.

## Files

- `tools/release/binaries.test.ts`

## Acceptance criteria

- No `36` is left in the test.
- The test passes, and validate passes.

## Verify

```bash
mise exec -- bun test tools/release/binaries.test.ts
```
