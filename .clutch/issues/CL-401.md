# CL-401: Add a PR size check

## Goal

Agent PRs stay small. In the research, top-tier repos have a median PR of about 108 changed lines and a p90 of about 900. n8n hard-fails above 1000.

## Steps

1. Branch `clutch/cl-401-pr-size`.
2. Add `clutch pr-size [--base <ref>] [--json]`. It counts added plus deleted lines from `git diff --numstat <base>...HEAD`, excluding `bun.lock`, `**/*.snap`, generated files listed in `clutch.yaml` `pr_size.exclude`, and `.clutch/**`.
3. Thresholds in `clutch.yaml` `pr_size`: `warn: 300`, `fail: 800`. The label `size/exempt` skips the fail, and only Brendan applies it.
4. Add CI job `pr-size` with `pull_request` and `permissions: { contents: read, pull-requests: write }`. It sets labels `size/S` (≤100), `size/M` (≤300), `size/L` (≤800) and `size/XL`.
5. Adopt `pr_size_limits`.

## Acceptance criteria

- Tests cover the exclusions and the thresholds.
- The label appears on the PR.

## Verify

```bash
mise exec -- bun run clutch pr-size --json
```
