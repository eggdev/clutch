# CL-401: Add a PR size check

## Goal

Agent PRs stay small. In the research, top-tier repos have a median PR of about 108 changed lines and a p90 of about 900. n8n hard-fails above 1000.

## Steps

1. Branch `clutch/cl-401-pr-size`.
2. Add `pr_size` to the `clutch.yaml` schema in `apps/cli/src/clutch-config/schema.ts` first. The schema rejects unknown top-level keys today.
3. Add `clutch pr-size [--base <ref>] [--json]`. It counts added plus deleted lines from `git diff --numstat <base>...HEAD`, excluding `bun.lock`, `**/*.snap`, generated files listed in `clutch.yaml` `pr_size.exclude`, and `.clutch/**`.
4. Thresholds in `clutch.yaml` `pr_size`: `warn: 300`, `fail: 800`. The label `size/exempt` skips the fail. Honor it only when the `labeled` event sender is the owner (`eggdev`, the handle in `.github/CODEOWNERS`).
5. Create the labels first with `gh label create --force --repo eggdev/clutch` for `size/S`, `size/M`, `size/L`, `size/XL` and `size/exempt`.
6. Add CI job `pr-size` with `pull_request` (types `opened`, `synchronize`, `reopened`, `labeled`) and `permissions: { contents: read, pull-requests: write }`. Check out with `fetch-depth: 0`, so the diff has the base history. It sets labels `size/S` (≤100), `size/M` (≤300), `size/L` (≤800) and `size/XL`.
7. Set `pr_size_limits` to `adopted` in `clutch.yaml`, and run `mise exec -- bun run clutch doctor --write-baseline`.

## Acceptance criteria

- Tests cover the exclusions and the thresholds.
- The label appears on the PR.
- A `size/exempt` label from anyone but the owner does not skip the fail.

## Verify

```bash
mise exec -- bun run clutch pr-size --json
```
