# CL-909: Add a deploy-on-green-main workflow skeleton

## Goal

A project deploys production after CI passes on `main`, from a skeleton that kickoff fills in.

## Context

From CL-605. Neighborhood's `deploy.yml` runs on `workflow_run` of CI, completed and successful, on `main` push events only. It uses `environment: production`, serializes runs with `concurrency: production`, runs migrations before traffic, and passes `BUILD_COMMIT` to each health route. Clutch has a kickoff slot for deploys but no workflow.

## Steps

1. Add `deploy.yml` with that trigger, environment and concurrency, and a kickoff slot for the deploy commands.
2. Document it in `docs/contributing/operations/rollback.md` next to Path B.

## Acceptance criteria

- With the slot filled, each green push to `main` deploys once, in order.
