# CL-414: Show the week's visual changes in the weekly digest

## Goal

The weekly digest shows the owner a contact sheet of the baselines that changed on each fleet repository's default branch in the last 7 days.

## Context

See the design note in CL-412, step 6. The digest already checks out each fleet repository. The contact sheet reads `git log`, so it makes no extra GitHub API call.

## Steps

1. Add `tools/journeys/visual-digest.ts`: list the baseline PNGs that changed in the last 7 days, and print a Markdown table of before and after thumbnails, linked to each commit.
2. Fetch the target's history in `weekly-digest.yml`, with a blob-less filter, and append the sheet to the summary.

## Acceptance criteria

- A week with changed baselines shows one row for each, before and after.
- A week with none says so in one line.

## Notes

`tools/journeys/visual-digest.ts` makes no API call. The images are `https://github.com/<repo>/blob/<sha>/<path>?raw=true` links, each inside a link to the file, so a viewer who cannot load the image can still open it. Whether a job summary shows images from a private repository depends on GitHub's image proxy. Check the first digest of Neighborhood, which is private, and switch to an uploaded artifact if the images do not load.
