# CL-485: List the iOS lane variable in the escape hatch table

## Goal

The escape hatch table lists the repository variable that turns the iOS lane of CI on.

## Context

- CL-484 made the `native-ios` job start only when the repository variable `CLUTCH_IOS_LANE` is `on`.
- Agent review named that variable a new escape hatch on PR 259. It is one: a repository that leaves it unset runs no iOS journey in CI.
- The table in `docs/contributing/harness-engineering.md#guardrail-files` lists where each hatch lives. It has no row for this one.
- The server merged PR 259 before the session could push the row.
- The `if` lives in a guardrail file, `.github/workflows/ci.yml`. The value of the variable is a GitHub setting. So a review sees a change to the `if`, and it does not see a change to the value.

## Steps

1. Branch `clutch/cl-485-ios-lane-hatch-row`.
2. Add one row to the table. Say where the hatch lives, and that the value is outside the repository.

## Files

- `docs/contributing/harness-engineering.md`

## Acceptance criteria

- The table has a row for `CLUTCH_IOS_LANE`.
- The row says that no review sees a change to the value.
