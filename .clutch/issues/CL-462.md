# CL-462: Hold a removed screen and tie a new feature to a user goal

## Goal

Two deterministic checks stop the product drifting from who it is for. This takes step 9 of CL-441.

## Context

System review, 2026-11-08: no check saw a removed feature, and no check tied a new feature to project intent.

## Steps

1. Hold a PR that deletes a screen or a route with no rename.
2. Require `goal:` from project intent on a PR that adds a feature, after kickoff.

## Files

- `tools/github/weaker-journeys.ts`, `tools/check-scope.ts`, `apps/cli/src/issues/parse.ts`, `docs/contributing/project-intent.md`

## Acceptance criteria

- A removed screen or route holds, and a renamed one does not.
- A new feature with no goal from project intent fails.

## Verify

`mise exec -- bun run validate`.
