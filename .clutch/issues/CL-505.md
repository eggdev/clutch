# CL-505: Add accessibility checks to journeys

## Goal

Journeys fail on serious accessibility violations.

## Steps

1. Branch `clutch/cl-505-a11y`.
2. Add `@axe-core/playwright` (pinned). In the journey harness (`tools/journeys/**`, a guardrail file), run axe after each journey step that renders a page. Fail on `serious` and `critical` violations.
3. Add the `a11y_checks` capability to the registry (as an extra level), with a doc page.

## Acceptance criteria

- `bun run journeys` passes.
- An injected unlabeled button fails a journey.

## Verify

```bash
mise exec -- bun run journeys
```
