# CL-913: Add a clutch delivery loop that takes an issue from next to merged

## Goal

One command takes an issue from `clutch issues next` to merged: branch, open, wait, fix the docs that agent review names, mark it done, and merge once approved.

## Context

CL-902 (Brendan, 2026-11-01): Clutch is the primary driver of the workflow, and "it can drive most". Today each lane strings `issues next`, `pr open`, `pr wait`, `pr failures`, `pr ready` and `pr merge` together by hand, from the deliver skill.

## Steps

1. Write the loop as a `clutch` command that stops at each owner gate (approval, a `HUMAN GATE` issue, a `one-way-door` change).
2. Keep each step its own command, so a person or an agent can take over at any point.

## Trigger

After CL-912, once the `pr` commands live in the binary.
