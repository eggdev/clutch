# CL-453: Fail a journeys run that tests nothing when a feature ships a screen

## Goal

The required `journeys` check cannot pass with nothing tested when the product has a screen.

## Context

Council review, 2026-11-08: `tools/journeys/run.ts` returned 0 when no journey was selected, and `docs/principles/proof-gates-code.md` says a run with no journey fails. A project before its first feature still passes.

## Steps

1. In `tools/journeys/run.ts`, fail when no journey ran and `missingJourneys` names a feature.
2. Update `docs/contributing/setup/verification.md`.

## Files

- `tools/journeys/run.ts`, `tools/check-journeys.ts`, `tools/journeys/run.test.ts`

## Acceptance criteria

- A repository with a shipped feature screen and no journey exits 1 and names the feature.
- A repository with no feature exits 0 and warns.

## Verify

`mise exec -- bun run validate`.
