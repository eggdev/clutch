# CL-304: Add a flaky-test quarantine registry with expiry

## Goal

A flaky test is quarantined with an owner and an expiry, not deleted or skipped silently.

## Steps

1. Branch `clutch/cl-304-flaky`.
2. Add `tools/flaky-tests.json`: `{tests:[{file, name, issue, until}]}`. It is a guardrail file.
3. Add `tools/check-flaky-tests.ts` with tests. It fails on an expired entry or an entry with a missing issue. Add root target `check-flaky-tests` and a `checks.md` row.
4. Quarantined tests run in a separate non-blocking CI step that retries them 3 times and reports.
5. Adopt `flaky_quarantine`.

## Acceptance criteria

- An expired fixture entry fails the check with a fix message.

## Verify

```bash
mise exec -- bun test tools/check-flaky-tests.test.ts
```
