# CL-002: Rename the in-repo scaffolding from project-template to Clutch

## Goal

Rename everything inside the repository from "project-template" or "template" (the product name) to "Clutch". Keep the GitHub repository name unchanged. That rename is the human gate CL-006.

## Context

GitHub code search for `project-template` in the repo returns these files at 384c9c39:

- `package.json` (`"name": "project-template"`). Portless derives the dev URL from this name. The URL becomes `http://clutch.localhost:1355`.
- `README.md`
- `apps/cli/src/config.ts` (XDG folder `project-template/config.json`)
- `apps/cli/src/merge-package-json.test.ts`, `apps/cli/src/install-template.test.ts`
- `docs/contributing/setup/local-development.md`, `docs/contributing/setup/nx.md`, `docs/contributing/architecture/review-runtime.md`
- `.agents/skills/verify/verification.json` (portless URL, guardrail file)
- `packages/sync/config/origins.test.ts` (portless origin)
- `apps/nx-cache/wrangler.jsonc` (Cloudflare worker name)
- `.delivery/agent-workflow.md`, `.delivery/consolidate-review-tooling.md`
- `bun.lock`

The CLI is `apps/cli`. `apps/cli/package.json` has `"name": "cli"` and `"bin": { "template": "src/main.ts" }`.

## Steps

1. Branch `clutch/cl-002-rename`.
2. `rg -n --hidden -i "project-template|project template" -g '!bun.lock' -g '!.clutch/**'` and save the list in the PR body.
3. Root `package.json`: set `"name": "clutch"`. Add the script `"clutch": "bun apps/cli/src/main.ts"`.
4. `apps/cli/package.json`: set `"name": "@repo/cli"` and `"bin": { "clutch": "src/main.ts" }`. Remove the `template` bin. Do not add an alias or any back-compat command. The CLI is only `clutch`, and every package uses the `@repo` scope.
   - Replace every `template <command>` invocation in docs, skills, hooks, scripts and help text with `clutch <command>`. Find them with `rg -n --hidden "\btemplate (setup|doctor|review|install)\b|bunx template|bun x template" -g '!.clutch/**'`.
5. `apps/cli/src/config.ts`: use the XDG path `clutch/config.json`. Add a one-time migration: when `clutch/config.json` does not exist and `project-template/config.json` does, copy it to the new path and use the new path from then on. This is a file migration, not a command alias. Add a test for the migration in `apps/cli/src/config.test.ts` (create it if missing).
6. Replace the portless URL `project-template.localhost` with `clutch.localhost` in docs, `verification.json` and `origins.test.ts`.
7. Replace the product name in `README.md`, `apps/cli/README.md`, `docs/**` and the help text in `apps/cli/src/main.ts`. Keep the install branch name `template/install` and the manifest path `.template-install/manifest.json` unchanged. Downstream repos depend on them (open question 2).
8. `docs/contributing/architecture/primitives.yaml`: change `install-cli` to `id: clutch-cli`, `name: Clutch CLI`, summary "Installs, syncs and checks Clutch in a project, and runs the kickoff stages with an agent."
9. Do NOT change `apps/nx-cache/wrangler.jsonc` worker `name`. A worker rename is a deploy (human gate). Add a note in the PR body.
10. Do NOT edit `.delivery/*`. CL-004 migrates those files.
11. `mise exec -- bun install` to refresh `bun.lock`. Then format and validate.
12. Commit "Rename the project to Clutch inside the repository", push, draft PR, update tracker, notify `status`.

## Acceptance criteria

- `rg -n -i "project-template" -g '!bun.lock' -g '!.clutch/**' -g '!.delivery/**'` prints only the `wrangler.jsonc` worker name and the config migration in `config.ts`.
- `apps/cli/package.json` has no `template` bin, and `rg -n "@clutch/" --hidden -g '!bun.lock' -g '!.clutch/**'` prints nothing.
- `mise exec -- bun run clutch --help` prints usage that names `clutch`.
- `bun apps/cli/src/main.ts --help` still works.
- No `template` command or alias exists. `rg -n --hidden "\btemplate (setup|doctor|review|install)\b" -g '!.clutch/**'` prints nothing.
- `mise exec -- bun run dev --check` reports `clutch.localhost` URLs.
- validate passes.
