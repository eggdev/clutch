# CL-450: Await the intake check before its test repo is removed

## Goal

The intake-doc tests read their temporary repository before it is removed, so they never fail at random.

## Context

- `apps/cli/src/factory/intake-doc.test.ts` failed in CI on eggdev/clutch#226 (run 42324940169), in the #230 council review, and on `main` at 28a5701 (run 42375439371). It passed on each rerun and never failed locally.
- Cause: the `check` helper holds the repository with `await using` and returns `checkIntakeDoc(...)` without `await`. The function returns before the check reads `.clutch/README.md`, so `await using` removes the folder while the read is still pending. On a busy CI runner the removal sometimes wins, and the check sees no README.
- A search of every `await using` in the repo found no other place where the returned call is still pending when the folder goes.

## Steps

1. Branch `clutch/cl-450-intake-test-race`.
2. `return await checkIntakeDoc(...)` in the helper, with a comment that says why.

## Files

- `apps/cli/src/factory/intake-doc.test.ts`

## Acceptance criteria

- The helper awaits the check before the repository is removed.
- `bun run validate` passes.

## Verify

`mise exec -- bun test apps/cli/src/factory/intake-doc.test.ts`.
