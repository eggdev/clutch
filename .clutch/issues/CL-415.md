# CL-415: Record a disposition for each agent review finding

## Goal

After CI finishes, the agent answers every agent review finding on its PR, from every head, in one `## Review disposition` comment. It fixes the finding, or says why not, or names the owner's decision. `pr merge` refuses a PR with a finding that has no answer.

## Context

Lane E's PRs #181, #185 and #186 (2026-11-03) showed the gap. The `babysit-pr` skill said to read the findings "on the head commit" only, and no step made an agent run it. The PRs show three failure modes:

- A reviewer asked twice for an escape-hatch row (#185, comments 4458124128 and 4458291514). The row never came, because each fix push answered only the latest summary.
- A later review dropped an owner finding (`check-flaky-tests`, #186, 4458225890) whose cause stayed in the diff.
- No PR recorded which push fixed which comment, or why an owner item stays open.

A fourth review of #186 found two real defects among its owner findings: the visual step failed open, and the PR body was not fenced in the judge prompt. An agent that reads only the blocking count misses those.

## Steps

1. Add `tools/github/findings.ts` and `bun run pr findings <number> [--check]`. It groups each inline finding by level and file across every head, and matches each group to the latest `## Review disposition` comment by comment id, or by path and level. It reads with 3 `gh` calls.
2. `pr merge` refuses while a finding has no disposition.
3. Make step 7 of `babysit-pr` the disposition pass, and add "Answer each finding" to `pull-requests.md` and the command index.

## Files

- add `tools/github/findings.ts`, `tools/github/findings.test.ts`
- edit `tools/github/pr.ts`, `tools/github/merge.ts`, `.agents/skills/babysit-pr/SKILL.md`, `.agents/skills/deliver/references/pull-requests.md`, `.agents/skills/deliver/references/commands.md`

## Acceptance criteria

- `pr findings` lists a finding that only an earlier head raised.
- `pr findings --check` exits 1 until each finding has a line, and 0 after.
- `pr merge` refuses a PR with an unanswered finding and names the command.
