# CL-461: Deploy on green main and prove the core journeys on production

## Goal

Each green `main` deploys and proves its core journeys on production. This takes the skeleton of CL-909 and the core of CL-443.

## Context

System review, 2026-11-08: no workflow deployed, and production proof was absent.

## Steps

1. Add `deploy.yml` on a green CI push to `main`.
2. Add `tools/deploy.ts`: `run`, `prove` and `check`.
3. Add `--production <url>` to `tools/journeys/run.ts`, which runs only core journeys.

## Files

- `.github/workflows/deploy.yml`, `tools/deploy.ts`, `tools/journeys/run.ts`, `apps/cli/src/clutch-config/`

## Acceptance criteria

- A named deploy that fails is red.
- Two production failures mark it red and ask the owner.
- A project past kickoff with an app and no deploy fails the check.

## Verify

`mise exec -- bun run validate`, and `tools/deploy.test.ts`.
