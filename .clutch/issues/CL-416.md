# CL-416: Hold auto-merge until each review finding has a disposition

## Goal

Auto-merge holds an agent PR while an agent review finding, from any head, has no line in its `## Review disposition` comment, as `pr merge` does after CL-415.

## Context

CL-415 adds the disposition pass and makes `pr merge` refuse an unanswered finding. Auto-merge queues PRs with `gh pr merge --auto` and never runs `pr merge`, so an auto-merged PR can skip the pass. `tools/github/auto-merge*.ts` and `auto-merge.yml` are in the `one-way-door` tier, so Brendan decides. Start permissive: hold only on an unanswered `blocking` or `owner` finding, and report unanswered notes in the verdict.

## Steps

1. Read `prFindings` from `tools/github/findings.ts` in the auto-merge judge.
2. Add "a finding has no disposition" to the reasons it does not merge.
3. Measure on the dry-run verdicts for a week before it holds anything.

## Acceptance criteria

- A PR with an unanswered `blocking` or `owner` finding gets "would not auto-merge" with the finding named.
