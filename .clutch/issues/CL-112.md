# CL-112: Drop the unused id-token grant from agent review

## Goal

Agent review asks only for the permissions that it uses.

## Context

CL-105 found that `agent-review.yml` grants `id-token: write`. `anthropics/claude-code-action` uses that grant to trade the job's OIDC token for a Claude GitHub App token. Agent review passes `github_token: ${{ github.token }}`, so it never makes that trade. `gardening.yml` falls back to the Claude App token, so it keeps the grant.

## Steps

1. Branch `clutch/cl-112-agent-review-id-token`.
2. Remove `id-token: write` from the `agent-review` job in `.github/workflows/agent-review.yml`.
3. Update the `id-token: write` section of `docs/contributing/setup/ci-credentials.md`.

## Acceptance criteria

- Agent review runs and posts its comment on the PR without the grant.
- `check-workflows` and `check-workflow-lint` pass.

## Verify

```bash
mise exec -- bun nx run-many -t check-workflows check-workflow-lint
gh pr checks
```
