# CL-456: Let the server merge a green agent PR

## Goal

A green agent PR merges with no session and no person. A session that is still working keeps its PR a draft.

## Context

Council review, 2026-11-08. An agent's PR merged only when its session ran `pr merge`, and the main ruleset listed open threads as a hold. The owner wants work to reach the end without them.

## Steps

1. Remove the session-only rule from `.github/workflows/auto-merge.yml`.
2. Rejudge each open agent PR when `main` turns green.
3. Set `required_review_thread_resolution` to false in `.github/rulesets/main.json`.
4. Make `owner: agent` issues end merged in `deliver`.

## Files

- `.github/workflows/auto-merge.yml`, `.github/rulesets/main.json`, `.agents/skills/deliver/`

## Acceptance criteria

- A green agent PR is judged on a CI completion with no approval and no session.
- `bun run validate` passes.

## Verify

`mise exec -- bun run validate`.
