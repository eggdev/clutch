# CL-201b: Add clutch worktree rm and a dev server stop path

## Goal

One command removes a worktree safely. It refuses a dirty or unpushed checkout, and it stops that checkout's dev servers first.

## Context

- `tools/dev.ts` has only `--check`. It exits 1 when any server is down. It has no way to stop servers that a checkout started.
- `tools/dev.ts` is a guardrail file. Changes to it need Brendan's approval in the PR.
- The stop path must find only the servers of its own checkout. Other checkouts run their own dev servers.

## Steps

1. Branch `clutch/cl-201b-worktree-rm`.
2. Add a stop path to `tools/dev.ts`. Pick one design and state it in the PR:
   - Option A: `dev` writes a PID record for each server it starts under `.data/`, and `dev --stop` signals those PIDs.
   - Option B: `dev --stop` finds the processes by the lock file in `.data/dev.lock`.
     Option A is simpler to test. Pick A unless it fails.
3. Add `apps/cli/src/worktree/remove.ts`. Register the `rm` subcommand in `apps/cli/src/worktree-command.ts`.
   - `clutch worktree rm <slug> [--force]`: refuse a dirty tree or unpushed commits unless `--force`.
   - Stop that checkout's dev servers first, through the stop path from step 2. Do not import `tools/dev.ts`. Run it as a command.
   - Then call `remove` on the backend. Delete the branch only when it is merged.
4. Tests on a `gitRepo` fixture. Cover a dirty tree, unpushed commits, and a merged branch.

## Acceptance criteria

- `clutch worktree rm` refuses a dirty tree and refuses unpushed commits without `--force`.
- After `rm`, no dev server from that checkout is still running.
- Two worktrees can run `bun run dev` at once. `rm` on one does not stop the other.

## Verify

```bash
mise exec -- bun run clutch worktree new demo-a
# In a second terminal, start the dev servers in demo-a and leave them running.
# (cd ../clutch.worktrees/demo-a && mise exec -- bun run dev)
echo dirty > ../clutch.worktrees/demo-a/scratch.txt
mise exec -- bun run clutch worktree rm demo-a   # must refuse
rm ../clutch.worktrees/demo-a/scratch.txt
mise exec -- bun run clutch worktree rm demo-a
```
