# CL-138: Make pr merge see a code owner review that a ruleset requires

## Goal

`pr merge` refuses a PR that waits for a code owner's approval under the main ruleset.

## Context

- CL-137 made `pr merge` refuse while `reviewDecision` is `REVIEW_REQUIRED` or `CHANGES_REQUESTED`, because the owner's admin login can bypass the ruleset.
- The test PR #98, which touched `.agents/skills/README.md` after the ruleset went live, showed that a ruleset's code owner review leaves `reviewDecision` empty. GitHub reported `mergeStateStatus: BLOCKED` with every check green and `@eggdev` requested. So the CL-137 check would not fire.

## Steps

1. In `tools/github/merge.ts`, also refuse when `reviewDecision` is empty, `mergeStateStatus` is `BLOCKED` and a review is still requested.
2. Add the case to `tools/github/pr.test.ts`.

## Files

- `tools/github/merge.ts`, `tools/github/pr.test.ts`

## Acceptance criteria

- `pr merge` refuses a PR in the state of #98, and names the requested reviewer.

## Verify

```bash
mise exec -- bun test tools/github/pr.test.ts
```
