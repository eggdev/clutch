# CL-315: Run the CI checks on the owner's machine with a local CI service

## Goal

The CI checks of the owner's repositories run on his own machine and report to GitHub, with no GitHub Actions.

## Context

GitHub Actions is off, so no required check runs. The jobs stay defined in each repository's `.github/workflows/` files.

## Steps

1. Add `apps/local-ci/`: the poll loop, the trust rule, the job plan, the container run, the job image and the unit.

## Files

`apps/local-ci/` and its entry in `docs/contributing/architecture/primitives.yaml`.

## Acceptance criteria

- Each new head commit of a trusted pull request gets one status for each configured job.
- A fork, or an author that is not on the allowlist, never runs.
- A job container mounts nothing from the host, and a secret that cannot be read gives an `error` status.

## Verify

`mise exec -- bun test apps/local-ci`, then read the statuses of an open pull request.
