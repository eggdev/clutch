# CL-422: Run SAST in one job, and skip the scan on a docs-only PR

## Goal

Cut what SAST costs a private repository by half, with the same coverage.

## Context

Neighborhood is private, so each Actions minute is billed, and each job bills
at least one minute. On 2026-11-02 and 03, SAST ran 96 times at about 4 billed
minutes: `engine` 1, `semgrep` 2, `sast` 1. `sast` is a required check, so it
must report on each head commit. Scanning only when a PR opens would let later
pushes merge unscanned, so every push that changes a scanned file still scans.

## Steps

1. Merge `engine`, `codeql`, `semgrep` and `sast` into the one `sast` job.
   CodeQL runs its three languages in one init. Semgrep runs from its pinned
   image as a `docker://` step, which Renovate still updates.
2. Skip the scan when a PR changes only Markdown, images, changesets or
   tracker files.

## Files

- `.github/workflows/sast.yml`
- `docs/contributing/capabilities/codeql-sast.md`

## Acceptance criteria

- One job on each SAST run. The required check keeps its name, `sast`.
- A docs-only PR passes `sast` with a notice and no scan.
- A PR with a code change scans, with the same rules.

## Verify

- `mise exec -- bun run validate`
- This PR's own `sast` run, which scans with CodeQL in one job.
