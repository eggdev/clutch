# CL-593: Set the size limit of a pull request back to 1,000 lines

## Goal

The size limit of a pull request is 1,000 lines again.

## Context

On 2026-11-20 the owner asked for the rest of the sync engine work in one pull request, reviewed until a council scored it 9/10. That pull request changes about 5,500 lines, so it set `pr_size.max` in `clutch.yaml` to 6000 for itself. `tools/check-scope.ts` reads the limit from the head of a pull request. The owner agreed to pass the rule for that one change.

## Steps

1. Branch `clutch/cl-593-size-limit-back`.
2. Set `pr_size.max` in `clutch.yaml` to 1000, and remove the comment above it.

## Files

- `clutch.yaml`

## Acceptance criteria

- `pr_size.max` is 1000.
