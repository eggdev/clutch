# CL-316: Run Semgrep as the SAST engine of this repository

## Goal

The `sast` check of this repository passes on local CI.

## Context

GitHub Actions is off, and local CI runs the checks (CL-315). With `sast: auto`, this public repository runs CodeQL. CodeQL analyzes on local CI, but its upload asks GitHub for the Actions workflow run, which does not exist, so the job fails. Semgrep needs no upload. The owner approved the switch.

## Steps

1. Set `sast: semgrep` in `clutch.yaml`.
2. Give the one Semgrep finding its reason in `.github/workflows/deploy.yml`, as Neighborhood does.

## Files

`clutch.yaml` and `.github/workflows/deploy.yml`

## Acceptance criteria

- The `sast` job runs Semgrep on a pull request and passes when Semgrep reports no finding.

## Verify

Read the `sast` status that local CI posts on the pull request of this change.
