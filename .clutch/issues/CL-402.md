# CL-402: Add merge_group triggers to required workflows

## Goal

The required workflows run in a merge queue.

## Steps

1. Branch `clutch/cl-402-merge-group`.
2. Add `merge_group:` to `on:` in `ci.yml`, `codeql.yml` and `agent-review.yml`. Agent review must pass in the queue: skip the review and succeed on `merge_group`, because it already ran on the PR.
3. Add a `check-workflows` rule: a workflow whose job name is a required check must have `merge_group`. Read the required list from `clutch.yaml` `required_checks`.

## Acceptance criteria

- `check-workflows` passes and fails on a fixture without `merge_group`.

## Verify

```bash
rg -n "merge_group" .github/workflows
mise exec -- bun nx run check-workflows
```
