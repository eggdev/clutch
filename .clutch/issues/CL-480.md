# CL-480: Keep the tracker file out of pull request branches

## Goal

A pull request branch does not change `.clutch/TRACKER.md`.

## Context

- The release rewrites `.clutch/TRACKER.md` on `main` after each merge.
- A branch that changes that file conflicts with `main` after each release.
- On 2026-11-12 a stack of nine pull requests stopped after its first merge.
- Each later sync hit the same conflict.
- `.clutch/README.md` says a pull request commits only its own `issues/CL-NNN.md` files.

## Steps

1. Branch `clutch/cl-480-tracker-off-branches`.
2. Find out first: which command writes `.clutch/TRACKER.md` on a branch. Check `pr open`, `pr ready` and `clutch issues`.
3. Stop that command from writing the file on a branch.
4. Find out first: whether a check can refuse a branch change to that file. If one can, add it.
5. Add a test for the change.

## Files

- `.clutch/TRACKER.md`
- `.clutch/README.md`
- `tools/github/pr.ts`

## Acceptance criteria

- A pull request branch does not change `.clutch/TRACKER.md`.
- A stack syncs after a release with no conflict on that file.

## Verify

- `mise exec -- bun run clutch issues --check`
- `mise exec -- bun run validate`
