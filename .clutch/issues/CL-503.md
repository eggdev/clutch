# CL-503: Add clutch metrics for factory observability

## Goal

Weekly numbers on how the factory runs.

## Steps

1. Branch `clutch/cl-503-metrics`.
2. Add `clutch metrics [--since 14d] [--repo OWNER/NAME] [--json]`. It uses `gh api` reads only. Every `gh api` call takes `--repo OWNER/NAME`, so the same command reads another repo. It reports:
   - PRs merged per day
   - median time from open to merge
   - the CI p50 and p90 duration from `actions/runs`
   - the CI failure rate
   - the issues done from `.clutch/issues`. Count these only for the checkout. With `--repo` for another repo, report the field as unavailable.
3. PR size and the agent share are in CL-503b, after CL-401 and CL-404.
4. CL-504 adds the weekly workflow that runs this command.

## Acceptance criteria

- `clutch metrics --json` returns every field in this issue for the template repo.

## Verify

```bash
mise exec -- bun run clutch metrics --since 30d --json | jq
```
