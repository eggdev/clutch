# CL-503: Add clutch metrics for factory observability

## Goal

Weekly numbers on how the factory runs.

## Steps

1. Branch `clutch/cl-503-metrics`.
2. Add `clutch metrics [--since 7d] [--json]`. It uses `gh api` reads only. It reports:
   - PRs merged per day
   - median time from open to merge
   - median PR size
   - the agent share by author allowlist
   - the CI p50 and p90 duration from `actions/runs`
   - the CI failure rate
   - the issues done from `.clutch/issues`
3. CL-504 adds the weekly workflow that runs this command.

## Acceptance criteria

- `clutch metrics --json` returns every field for the template repo.

## Verify

```bash
mise exec -- bun run clutch metrics --since 30d --json | jq
```
