# CL-472: Record an owner finding for the digest, and do not hold the pull request for it

## Goal

A finding of agent review that today waits for the owner no longer holds the merge. The weekly digest lists each one, so the owner can find a problem after the fact.

## Context

- The owner said on 2026-11-12 that a change which passes its checks should merge with no word from him, and that he pays a problem back after he finds it.
- `blockers` in `tools/github/auto-merge-rules.ts` holds a PR for each `owner` finding. `docs/contributing/review.md` gives two causes: a hard-core path, and a weaker check.
- On PR 251, four review passes opened 55 `owner` threads. Most repeated an earlier pass, and each one waited for the owner.
- The main ruleset requires each review thread to be resolved. An `owner` thread that stays open holds the merge too.
- A major change still waits for the owner: see CL-463 and CL-464.

## Steps

1. Branch `clutch/cl-472-owner-findings-to-digest`.
2. Write the failing tests first, in the tests of `tools/github/auto-merge-rules.ts` and of the babysit answers.
3. Take the owner findings out of `blockers`. Keep them in the verdict as a list that holds nothing.
4. In a babysit round, answer an `owner` thread with one sentence that says where the finding is recorded, and resolve it.
5. Give the weekly digest a section that lists each owner finding of the week with its PR.
6. Move `docs/contributing/review.md`, the `babysit-pr` skill and `.agents/skills/deliver/references/pull-requests.md` with the rule.

## Files

- `tools/github/auto-merge-rules.ts`, `tools/github/babysit-answer.ts`, `tools/github/status.ts`, `tools/github/merge.ts`
- `.github/workflows/weekly-digest.yml` and the script that it runs
- `docs/contributing/review.md`, `.agents/skills/babysit-pr/SKILL.md`, `.agents/skills/deliver/references/pull-requests.md`

## Acceptance criteria

- A PR with owner findings, green checks and no blocking finding merges with no person.
- The next weekly digest lists each of those findings with its PR and its file.
- A blocking finding still fails the `agent-review` check.
