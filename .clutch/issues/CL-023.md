# CL-023: Make the spaces sync test wait for events, not fixed sleeps

## Goal

`apps/api/src/spaces.test.ts` "two users in different spaces get only the records of their groups" fails at random under CI load. Make it deterministic.

## Context

- CI on `main` failed once after the merge of #7 (run 40970591296). The last backfill held `secret,design`, not `secret`.
- The test orders its steps with `Effect.sleep('100 millis')`. When the server is slow, the `design` space record can arrive in the backfill after B joins.
- It passed 5 of 5 runs on a local machine.
- Brendan may slim the starter app later. If the sync starter goes, close this issue as part of that work.

## Steps

1. Branch `clutch/cl-023-spaces-test`.
2. Replace each sleep with a wait on the event the next step needs: the `Groups` message, the delta that holds the record, or the push result.
3. Decide whether a space record belongs in the backfill of its own group. Assert that rule. Do not loosen the assertion to accept both results.
4. Run the test 20 times in a loop, and run validate.

## Files

- edit `apps/api/src/spaces.test.ts`

## Acceptance criteria

- The test has no fixed sleeps.
- `for i in $(seq 20); do mise exec -- bun test apps/api/src/spaces.test.ts; done` passes every time.
- validate passes.

## Verify

```bash
for i in $(seq 20); do mise exec -- bun test apps/api/src/spaces.test.ts || break; done
mise exec -- bun run validate
```
