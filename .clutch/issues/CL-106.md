# CL-106: HUMAN GATE: Turn on the main ruleset, secret scanning and push protection

## Goal

Brendan applies the repo settings that agents need before many PRs run in parallel.

## Gate

Stop. Changing repo settings, rulesets and secret scanning needs Brendan.

## Steps (agent)

1. Prepare the exact commands in the notify message and in this issue. Do not run them.
   - Secret scanning and push protection: `gh api -X PATCH repos/eggdev/clutch -F security_and_analysis[secret_scanning][status]=enabled -F security_and_analysis[secret_scanning_push_protection][status]=enabled`
   - Main ruleset: a JSON file at `/tmp/main-ruleset.json` with target `branch` and include `~DEFAULT_BRANCH`. Its rules: `pull_request` (0 approvals while Brendan is the only reviewer, dismiss stale reviews), `required_status_checks` (`validate`, `journeys`), `non_fast_forward` and `deletion`. Bypass: the repo admin role. Command: `gh api -X POST repos/eggdev/clutch/rulesets --input /tmp/main-ruleset.json`
   - Optional: install the Renovate app (CL-104).
2. `clutch notify question "CL-106: P1 needs repo settings. Commands are in .clutch/issues/CL-106.md. Approve to run, or apply them yourself."`
3. After Brendan acts, run `clutch doctor --remote --check` and paste the result in this issue.

## Acceptance criteria

- `clutch doctor --remote` reports `protected_main` and `secret_scanning` present.
