# CL-703: Restore the Bar Savvy ratchets with clutch ratchet

## Goal

Bring back the ratchets that ADR 0001 removed (package-graph tiers), and move the suppression ratchet onto `clutch ratchet`.

## Steps

1. Branch `clutch/cl-703-ratchets` from `epic/refactor`.
2. Add a decision record in Bar Savvy `docs/contributing/decisions/` that supersedes the ratchet part of ADR 0001. Cite Clutch CL-301.
3. Seed `.clutch/ratchets.json` with `lint-suppressions` (the semantics of `check-lint-suppressions.cjs`) and `package-graph-tiers` (a command that prints `path:count`).
4. Keep `packages/lint-rules/architecture-exceptions.ts` as a shrink-only list. Add a ratchet that counts its entries.
5. Add `check-ratchets` to Bar Savvy `checks`.

## Acceptance criteria

- A new suppression fails `check-ratchets`.
- Removing one lowers the baseline through `clutch ratchet update`.

## Verify

```bash
bun ~/src/clutch/apps/cli/src/main.ts ratchet check --root ~/src/bar-savvy-web
```
