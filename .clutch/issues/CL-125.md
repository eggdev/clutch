# CL-125: Print failing task output inline in validate

## Goal

When `validate` fails, its own output shows why.

## Context

Nx 23 picks the `summary` output style when it detects an AI agent. That style prints one line per failing task, with the path of its log under `~/.nx/.../terminalOutputs/`. Agents then dig the error out of that file. Nx's `static-failures-only` style prints each failing task's full output and one line for each passing or cached task. It is already Nx's default in CI.

## Steps

1. Branch `clutch/cl-125-validate-failure-output`.
2. Pass `--outputStyle=static-failures-only` in the `validate` and `check` scripts in `package.json`, and in the pre-push hook (`tools/hooks/pre-push.ts`).
3. Say so in the Validate section of `docs/contributing/setup/checks.md`.

## Acceptance criteria

- A planted type error makes `validate` print the TypeScript error inline, and no `terminalOutputs` path.
- `validate` passes on the branch.

## Verify

```bash
mise exec -- bun run validate
```
