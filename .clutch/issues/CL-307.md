# CL-307: Add nested AGENTS.md files for the CLI, tools and runtime

## Goal

Scoped agent rules near the code, each 20 lines or fewer.

## Context

- `tools/check-file-size.ts` has `fixed: { 'AGENTS.md': 20 }`. It is an exact-path map, so it caps only the root file. A `**/AGENTS.md` cap needs a glob match in the check loop.
- `tools/check-file-size.test.ts` does not exist yet.
- There is no root `CLAUDE.md`. Whether to add one is a separate decision, and this issue does not add it.

## Steps

1. Branch `clutch/cl-307-nested-agents`.
2. Add `apps/cli/AGENTS.md`, `tools/AGENTS.md` and `packages/runtime/AGENTS.md`. Each one is a map: the commands, the test command, the conventions and the links.
3. Extend `tools/check-file-size.ts` so that `fixed` also caps every `**/AGENTS.md` at 20 lines. Add the glob match in code, not only a new key. Create `tools/check-file-size.test.ts` with a test for it.
4. Make Claude Code pick them up. Claude Code reads nested `CLAUDE.md` files. Add a `CLAUDE.md` symlink or an `@AGENTS.md` include in each folder.
5. Adopt `nested_agent_rules`.

## Acceptance criteria

- `check-file-size` fails a 21-line nested `AGENTS.md` in a test.

## Notes

- A root `CLAUDE.md` is a separate decision. Record it as its own issue if Brendan wants one.

## Verify

```bash
wc -l apps/cli/AGENTS.md tools/AGENTS.md packages/runtime/AGENTS.md
mise exec -- bun test tools/check-file-size.test.ts
```
