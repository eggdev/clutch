# CL-307: Add nested AGENTS.md files for the CLI, tools and runtime

## Goal

Scoped agent rules near the code, each 20 lines or fewer.

## Steps

1. Branch `clutch/cl-307-nested-agents`.
2. Add `apps/cli/AGENTS.md`, `tools/AGENTS.md` and `packages/runtime/AGENTS.md`. Each one is a map: the commands, the test command, the conventions and the links.
3. Extend `tools/check-file-size.ts` `fixed` to cap every `**/AGENTS.md` at 20 lines, with a test.
4. Make `.claude` pick them up. Claude Code reads nested `CLAUDE.md`. Add a `CLAUDE.md` symlink or an `@AGENTS.md` include, matching the root setup.
5. Adopt `nested_agent_rules`.

## Acceptance criteria

- `check-file-size` fails a 21-line nested `AGENTS.md` in a test.

## Verify

```bash
wc -l apps/cli/AGENTS.md tools/AGENTS.md packages/runtime/AGENTS.md
mise exec -- bun test tools/check-file-size.test.ts
```
