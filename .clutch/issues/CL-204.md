# CL-204: Add clutch checks --changed for a fast affected-only check

## Goal

Run only the checks for the changed projects: typecheck, test and lint for affected Nx projects, plus the root checks when root files change. A one-file change under `apps/cli` finishes in under 60 s.

## Steps

1. Branch `clutch/cl-204-checks-changed`.
2. Add `apps/cli/src/checks-command.ts`: `clutch checks --changed [--base <ref>]`. Register it in `apps/cli/src/commands.ts`. The name is `checks`, not `verify`, so it does not collide with the verify skill or `tools/verification/verify.py`.
   - The base defaults to `git merge-base origin/main HEAD`. CL-303 uses `CHECK_BASE` from `.github/workflows/ci.yml` for the same job. Share one base helper with CL-303. CL-303 is P3, so whichever issue lands first owns the helper, and the other reuses it.
   - It runs `nx affected -t typecheck test lint format-check --base=<base>`. Decide whether argv starts with `bun nx` or `nx`. Use the same choice in the tests.
   - It adds `nx run clutch:checks` when a changed path is at the root or under `tools/`, `docs/` or `.github/`.
   - It prints the elapsed time and warns above 60 s.
3. Tests with `fakeBin` for `nx` assert the arguments.
4. The pre-push hook still runs the full set. Do not change `tools/hooks/pre-push.ts`.

## Acceptance criteria

- On a one-file change in `apps/cli`, the command finishes in under 60 s on the Spark.

## Verify

```bash
time mise exec -- bun run clutch checks --changed
```
