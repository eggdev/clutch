# CL-204: Add clutch verify --changed for a fast affected-only check

## Goal

Run in under 60 s on a typical PR: typecheck, test and lint for affected Nx projects, plus the root checks when root files change.

## Steps

1. Branch `clutch/cl-204-verify-changed`.
2. Add `apps/cli/src/verify-command.ts`: `clutch verify --changed [--base <ref>]`.
   - The base defaults to `git merge-base origin/main HEAD`.
   - It runs `nx affected -t typecheck test lint format-check --base=<base>`.
   - It adds `nx run clutch:checks` when a changed path is at the root or under `tools/`, `docs/` or `.github/`.
   - It prints the elapsed time and warns above 60 s.
3. Tests with `fakeBin` for `nx` assert the arguments.
4. The pre-push hook still runs the full set. Do not change `tools/hooks/pre-push.ts`.

## Acceptance criteria

- On a one-file change in `apps/cli`, the command finishes in under 60 s on the Spark.

## Verify

```bash
time mise exec -- bun run clutch verify --changed
```
