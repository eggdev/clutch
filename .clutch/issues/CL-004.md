# CL-004: Make .clutch/issues the single task tracker

## Goal

Keep one status list in the repository. Point the deliver skill and contributor docs at `.clutch/issues/`, and move the `.delivery/` records into it.

## Context

- `.agents/skills/deliver/references/task-records.md` says "Do not create a second status list in the repository" and names `.delivery/*.md` as the fallback tracker with states idea, ready, active, blocked, review, done.
- `.delivery/agent-workflow.md` and `.delivery/consolidate-review-tooling.md` exist. The second one is blocked on PR #2 (the `delete_repo` scope is missing).
- `docs/contributing/delivery.md` and `docs/contributing/agent-workflow.md` describe task records.
- Map the states like this: idea and ready become todo, active becomes in_progress. blocked, review and done stay the same.

## Steps

1. Branch `clutch/cl-004-one-tracker`.
2. Convert each `.delivery/*.md` to `.clutch/issues/CL-8NN.md` (CL-801, CL-802). Use phase `P0`, keep the outcome as the title and the body as is, and map the state. Delete the `.delivery/` files with `git mv` so history follows.
3. Edit `task-records.md`: the fallback tracker is `.clutch/issues/<id>.md` with the frontmatter from `.clutch/README.md`. Keep the external tracker rule (Linear or GitHub Issues) first if configured.
4. Edit `docs/contributing/delivery.md` and `docs/contributing/agent-workflow.md` only where they name `.delivery/`. Keep Simplified Technical English: 25 words per sentence at most, no em dash, and none of the words rejected in `docs/contributing/glossary.md`.
5. `rg -n "\.delivery" --hidden -g '!.clutch/**'` prints nothing.
6. `clutch issues --write`, validate, commit "Track tasks in .clutch/issues", draft PR.

## Files

- move `.delivery/*.md` to `.clutch/issues/CL-801.md`, `CL-802.md`
- edit `.agents/skills/deliver/references/task-records.md`, `docs/contributing/delivery.md`, `docs/contributing/agent-workflow.md`, `.clutch/TRACKER.md`

## Acceptance criteria

- No `.delivery/` folder remains.
- `rg "\.delivery"` finds no reference outside `.clutch/`.
- The skill tests pass (`skill-tests` target runs in validate).
