# CL-510: Generate CODEOWNERS from areas, and let owners auto-merge their own areas

## Goal

A project with several engineers routes each PR to the owners of the paths it touches, and a PR inside one owner's area merges without anyone else.

## Context

In the 2026-10-30 research over 58 repositories (see `.clutch/PLAN.md`), dense ownership grows with team size (median CODEOWNERS rules: 0 for solo, 62 for large teams). nixpkgs merges a PR only when the commenter maintains every touched package. Clutch has 56 rules, all owned by `@eggdev`.

## Steps

1. Branch `clutch/cl-510-ownership`.
2. Add an `owners` map to `clutch.yaml` (area glob to GitHub handles), filled at kickoff. Generate `.github/CODEOWNERS` from it with `clutch owners --write`, and check it with `--check`.
3. Extend auto-merge (CL-404): a `risk/medium` PR whose approver owns every touched area may merge without the repository owner.

## Files

- `clutch.yaml` schema, `apps/cli/src/owners.ts`
- `.github/CODEOWNERS`
- `.github/workflows/auto-merge.yml`

## Acceptance criteria

- `clutch owners --check` fails on a hand edit.
- The dry-run names the owner rule on a medium PR.

## Verify

```sh
mise exec -- bun run clutch owners --check
```
