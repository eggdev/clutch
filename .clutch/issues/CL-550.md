# CL-550: Fail a matchMedia or a window that a component holds under a local name

## Goal

The rule `repo-layout/no-viewport-reads` fails code that gives `matchMedia` or the window a local name, because lint cannot follow that name.

## Context

CL-541 added the rule, and it merged when its checks passed. Agent review then found a gap. `const media = window.matchMedia` and `const media = matchMedia` pass, so `media('(min-width: 600px)')` reads the width unseen. `const view = window` passes too, so `view.innerWidth` is unseen. The message of the rule says that a `matchMedia` under a local name fails, and that was true only for `const { matchMedia } = window`.

## Steps

1. Branch `clutch/cl-550-viewport-aliases`.
2. Fail a `matchMedia`, read bare or through the window, that code assigns to a name.
3. Fail a `window`, `globalThis` or `self` that code assigns to a name.
4. Keep a `typeof` test and the window as an argument of a call passing.

## Files

- `tools/lint/layout-policy.mjs`, `tools/lint/layout-policy.test.ts`
- `docs/contributing/setup/lint-rules.md`

## Acceptance criteria

- `const media = window.matchMedia`, `const media = matchMedia` and `const view = window` each fail lint in a component.
- `typeof window === 'undefined'` and `window.addEventListener(...)` pass.
- No existing code breaks the rule.
