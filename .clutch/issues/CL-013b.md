# CL-013b: Let a person keep or take each edited managed file during sync

## Goal

When `clutch sync` finds a `managed` file that the project edited, it asks instead of stopping. The answer is remembered, so sync asks again only when Clutch changes that file again (decision by Brendan, 2026-10-29).

## Steps

1. Branch from CL-013.
2. In a terminal, `clutch sync` asks for each edited file: keep yours, take Clutch's, or show the diff first. Use `@clack/prompts`, which the CLI already uses.
3. Without a terminal, or with `--json`, sync lists the files that need a decision and exits 2. `--keep <path>` and `--take <path>`, each repeatable, decide them.
4. A kept file records the Clutch hash it declined in `.clutch/lineage.json` `kept: {path: hash}`. Sync skips that file until the Clutch hash changes.
5. Update `.agents/skills/deliver/references/` or the sync docs so an agent asks the owner and passes `--keep` or `--take`. An agent never decides alone.

## Acceptance criteria

- An edited `knip.jsonc`, kept once, does not come up again until Clutch changes `knip.jsonc`.
- `--take` replaces the file and records the new hash.
- Without a terminal, sync never waits on a prompt.
- validate passes.
