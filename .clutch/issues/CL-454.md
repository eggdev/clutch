# CL-454: Remove the revert brake and the owner default on unanswered comments

## Goal

Two steps that send work to the owner with no product decision are gone.

## Context

Council review, 2026-11-08. The brake dropped medium PRs back to the owner when reverts rose, and the owner said "reverts are whatever to me". An unanswered PR comment defaulted to an owner decision, which stops the owner for a session's own gap.

## Steps

1. Delete `tools/github/auto-merge-brake.ts`, and judge each run at the configured step.
2. Keep the revert metric as a report only.
3. Leave a comment with no answer open for the next round.

## Files

- `tools/github/auto-merge.ts`, `tools/github/auto-merge-rules.ts`, `tools/github/babysit-answer.ts`, `tools/github/babysit-apply.ts`

## Acceptance criteria

- A run judges at the configured step whatever the revert rate is.
- A comment with no answer gets no reply, and does not go to the owner.
- `bun run validate` passes.

## Verify

`mise exec -- bun run validate`.
