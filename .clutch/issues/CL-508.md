# CL-508: Let a release ship a migration that clutch sync runs

## Goal

A breaking Clutch change can ship a script that rewrites a project, so the upgrade is a command and not a chore.

## Context

In the 2026-10-30 research over 58 repositories (see `.clutch/PLAN.md`), codemods ship with breaking changes in mastra, workers-sdk and gitlab. Defer the build until the first real breaking template change needs it.

## Steps

1. Branch `clutch/cl-508-migrations`.
2. A changeset may name `.clutch/migrations/<version>.ts`. `clutch sync` runs each migration between the project release and the target, in order, before it copies files.
3. A migration is idempotent and has a test with a fixture project.

## Files

- `apps/cli/src/sync/`
- `.clutch/migrations/`

## Acceptance criteria

- A fixture project two releases behind runs both migrations once.

## Verify

```sh
mise exec -- bun test apps/cli/src/sync
```
