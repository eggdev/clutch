# CL-006: HUMAN GATE: Rename the GitHub repository to eggdev/clutch

## Goal

Rename `eggdev/project-template` to `eggdev/clutch` on GitHub.

## Gate

Stop. Do not run this. Ask Brendan with the text below and wait for the reply.

## Steps (agent)

1. When CL-002 is `done`, ask Brendan:
   "CL-006: CL-002 is merged. Please rename eggdev/project-template to eggdev/clutch (Settings > General > Repository name), or reply 'approved' and I run: gh repo rename clutch --repo eggdev/project-template --yes"
2. Set this issue to `blocked` with `owner: brendan` until the reply.
3. After the rename, on every machine: `git remote set-url origin git@github.com:eggdev/clutch.git` (keep the protocol already in use). Then `git fetch`.
4. Update references to the old URL: `rg -n "eggdev/project-template"`. Edit README links, `clutch.yaml` `template.repo` (after CL-007) and the downstream docs. One PR: "Point links at eggdev/clutch".
5. GitHub redirects the old name, but update `neighborhood` and `bar-savvy-web` references in the repo track issues anyway.

## Acceptance criteria

- `gh repo view eggdev/clutch --json name` returns `clutch`.
- `git remote get-url origin` names `eggdev/clutch` on the Spark checkout.
- `rg "eggdev/project-template"` prints nothing outside `.clutch/`.
