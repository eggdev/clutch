# CL-561: The gardening hold counts each added line of the review rules

## Goal

A gardening pull request that adds any line to the review rules waits for the owner.

## Context

CL-554 holds a gardening pull request that adds a line to `docs/contributing/review.md`. The test for an added line left out each line that starts with `+++ `, to skip the file line of a diff. The patch of the GitHub files listing has no such file line: it starts at the first hunk. So the test only left out a real added line whose text starts with `++ `. Such a rule would merge with no approval. Agent review found this on pull request 288 after the merge.

## Steps

1. Branch `clutch/cl-561-gardening-added-line`.
2. In `tools/github/bot-rule.ts`, count each line of the patch that starts with `+` and is not blank.
3. Add a test with an added line that starts with `++ `.

## Files

- `tools/github/bot-rule.ts`, `tools/github/bot-rule.test.ts`

## Acceptance criteria

- A gardening pull request whose patch of the review rules adds a line that starts with `++ ` waits for the owner.
- A blank added line still adds no rule.

## Verify

```sh
mise exec -- bun run validate
```
