# CL-306: Add the friction log and clutch friction

## Goal

Agents record friction while they work. Gardening turns it into rules.

## Context

- `docs/contributing/capabilities/friction-log.md` defines the file, the kinds and the rule for `AGENTS.md`.
- `clutch doctor` detects the log only when git tracks `.clutch/friction.jsonl`, so the empty file must be committed.
- CL-902 has dated friction notes from 2026-10-29 and 2026-10-30. Seed the log from them.

## Steps

1. Branch `clutch/cl-306-friction`.
2. Add `clutch friction add "<text>" [--issue CL-NNN] [--kind tooling|docs|check|flake] [--file <path>]`. It appends a JSON line `{at, issue, kind, text, branch}` to `.clutch/friction.jsonl`. The `--file` option lets tests use a temp file.
3. Add `clutch friction list [--since 7d] [--json]`.
4. Add one line to `AGENTS.md`: record any friction that cost more than 5 minutes.
5. Commit `.clutch/friction.jsonl` empty, then add one entry for each dated CL-902 note.
6. Adopt `friction_log`.

## Acceptance criteria

- Tests cover append and filter, and use `--file` with a temp file.
- The file stays valid JSONL.
- `clutch doctor` reports `friction_log` present.

## Verify

```bash
mise exec -- bun run clutch friction add "test entry" --kind tooling && tail -1 .clutch/friction.jsonl
# Remove the test line before you commit the file.
```
