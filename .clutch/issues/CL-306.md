# CL-306: Add the friction log and clutch friction

## Goal

Agents record friction while they work. Gardening turns it into rules.

## Steps

1. Branch `clutch/cl-306-friction`.
2. Add `clutch friction add "<text>" [--issue CL-NNN] [--kind tooling|docs|check|flake]`. It appends a JSON line `{at, issue, kind, text, branch}` to `.clutch/friction.jsonl`.
3. Add `clutch friction list [--since 7d] [--json]`.
4. Add one line to the operating rules: record any friction that cost more than 5 minutes.
5. Adopt `friction_log`.

## Acceptance criteria

- Tests cover append and filter.
- The file stays valid JSONL.

## Verify

```bash
mise exec -- bun run clutch friction add "test entry" --kind tooling && tail -1 .clutch/friction.jsonl
```
