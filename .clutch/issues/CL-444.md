# CL-444: Fold the decision records into the core docs, and retire the folder

## Goal

Clutch has no decision records. Each rule lives in the core doc that owns its subject: a principle, project intent, a skill or a setup page. A project's own "no" lives in project intent.

## Context

- Brendan, 2026-11-06: "There should realistically be no 'decisions' in this project. They should all be funnelled to critically important core documents."
- `docs/contributing/decisions/` holds 0001 to 0004. `tools/check-decisions.ts` checks them. 26 files link to the folder or name decision records, including `KICKOFF.md`, `README.md`, the kickoff skill, `docs/contributing/documentation.md`, `glossary.md` and `docs/principles/lean-agent-context.md`.
- `.clutch/risk.yaml` holds `docs/contributing/decisions/**` as one-way-door.
- An agent reads a rule where it works. A record is one more place to look, and it goes stale next to the page it amends.

## Steps

1. Fold each record into its owning doc, as a rule with its reason:
   - 0001 shrink-only ratchets: `docs/contributing/setup/checks.md`.
   - 0002 merge most PRs with no human: `docs/principles/proof-gates-code.md` and `docs/contributing/review.md`.
   - 0003 a pure Clutch sync takes owner findings as approved: `docs/contributing/agent-review.md`.
   - 0004 no design canvas tool: `.agents/skills/design-proposal/SKILL.md`.
2. Give project intent's "Later, not now" a slot for a project's own "no", with its revisit condition. Kickoff writes there.
3. Delete `docs/contributing/decisions/`, `tools/check-decisions.ts` and its wiring, and the `risk.yaml` rule.
4. Rewrite every link and mention, and remove the term from the glossary.
5. Make a Clutch sync move a project's records into its project intent, or name each one for the session to fold.

## Files

- `docs/contributing/decisions/`, `tools/check-decisions.ts`
- `docs/principles/`, `docs/contributing/`, `.agents/skills/kickoff/`, `.agents/skills/design-proposal/`
- `KICKOFF.md`, `README.md`, `clutch.yaml`, `.clutch/risk.yaml`, `clutch.files.yaml`
- the docs checks that name records: `tools/check-docs-claims.ts`, `tools/check-docs-temporal.ts`, `tools/check-sentences.ts`

## Acceptance criteria

- `rg -n "decision record|decisions/" --glob '!CHANGELOG.md' --glob '!.clutch/issues/**'` finds nothing.
- Each rule from 0001 to 0004 is in its owning doc.
- `bun run validate` passes.
