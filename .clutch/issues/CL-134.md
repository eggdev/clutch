# CL-134: Pin each required check to the GitHub Actions app

## Goal

A required check counts only when the GitHub Actions app reported it, so no other app or token can satisfy it.

## Context

From CL-605. Neighborhood's Bugbot gate (`tools/bugbot-review.mjs`) trusts a check run only when its app id and slug are Cursor's. Clutch's `main` ruleset requires `validate`, `journeys`, `secrets`, `commits`, `sast` and `agent-review` by `context` alone, with no `integration_id`. `tools/github/auto-merge.ts` also reads check runs by name. Any app, or a token with `checks: write`, could post a check run with one of those names.

## Steps

1. Branch `clutch/cl-134-pin-checks`.
2. Add `integration_id` for the GitHub Actions app (15368) to each required check in `.github/rulesets/main.json`, and apply it with `clutch ruleset --apply`.
3. In `tools/github/auto-merge.ts`, count a check run only when `app.slug` is `github-actions`. A test should show that a same-named run from another app is ignored.

## Files

- `.github/rulesets/main.json`, `tools/github/auto-merge.ts`, `tools/github/auto-merge.test.ts`.

## Acceptance criteria

- `clutch ruleset` shows each required check pinned to the GitHub Actions app.
- Auto-merge ignores a same-named check from another app.
