# CL-603: Sync Neighborhood to the latest Clutch release

## Goal

Close the 40-commit gap. The missing items include the template checks (`check-suppressions`, `check-agent-hooks` and others) and the agent hooks.

## Steps

1. Branch `clutch/cl-603-sync`. Pull the Clutch tags first: `git -C ~/src/clutch pull --tags`.
2. Run `bun ~/src/clutch/apps/cli/src/main.ts sync --check --root ~/src/neighborhood --json > /tmp/nb-sync.json` and list the planned changes and conflicts.
3. Each keep or take decision goes to Brendan. Ask him in the thread. Then rerun sync with `--keep <file>` or `--take <file>` for each file. He may approve one policy up front, such as taking all Clutch tooling, and you apply it one file at a time. Never decide a file yourself.
4. Split the PRs by group. First run `sync --only review` (the shared review tooling) and open a PR. Then run the full sync on a second branch and open a second PR.
5. Run Neighborhood validate after each PR.

## Acceptance criteria

- `clutch sync --check` exits 0.
- Neighborhood validate is green.

## Verify

```bash
bun ~/src/clutch/apps/cli/src/main.ts sync --check --root ~/src/neighborhood; echo $?
```

## Notes

- Sync follows the newest release tag `vX.Y.Z`. There is no `--latest` flag. `--to <tag or commit>` syncs once to a chosen revision.
