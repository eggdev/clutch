# CL-511: Budget the whole chain of agent instructions and test skill freshness

## Goal

Agent instructions stay small and current as more people add to them.

## Context

In the 2026-10-30 research over 58 repositories (see `.clutch/PLAN.md`), among repositories with 13 or more authors, a checked budget on agent instructions had the strongest link to shipping more than headcount predicts. hermes-agent fails CI when the AGENTS.md chain passes a share of the context window. airflow evaluates AGENTS.md changes A/B. The root `AGENTS.md` cap here covers one file only.

## Steps

1. Branch `clutch/cl-511-agent-budget`.
2. Add `check-agent-budget`: the root and every nested `AGENTS.md`, plus each skill `SKILL.md` front matter, stay under a total line budget in `tools/file-size-budgets.json`.
3. Each rule line in an `AGENTS.md` may point at the check that enforces it (`[check: <target>]`). The check fails when the target does not exist.
4. A skill freshness test fails when a `SKILL.md` names a file, script or command that no longer exists.

## Files

- `tools/check-agent-budget.ts`
- `tools/file-size-budgets.json`

## Acceptance criteria

- A nested AGENTS.md that pushes the chain over budget fails.
- A skill that names a deleted script fails.
