# CL-205: Add the repo MCP config for agents

## Goal

Agents get the same MCP servers in every checkout.

## Steps

1. Branch `clutch/cl-205-mcp`.
2. Add `.mcp.json` (Claude Code and Codex) and `.cursor/mcp.json` with servers that need no secret in the file. Start with Playwright MCP for journeys and the GitHub MCP read tools with token from env.
3. List the servers in `docs/contributing/setup/agent-tools.md`.
4. Adopt `mcp_config`.

## Acceptance criteria

- `claude mcp list` in the repo shows the servers.
- `gitleaks` finds no secret in the files.

## Verify

```bash
mise exec -- gitleaks dir .mcp.json .cursor/mcp.json --redact
```
