# CL-205: Add the repo MCP config for agents

## Goal

Agents get the same MCP servers in every checkout.

## Steps

1. Branch `clutch/cl-205-mcp`.
2. Add `.mcp.json` (Claude Code) and `.cursor/mcp.json` with servers that need no secret in the file. Start with Playwright MCP for journeys, pinned to one exact version (not `latest` or a range), and the GitHub MCP read tools with token from env. Codex is not in this issue. See Notes.
3. Create `docs/contributing/setup/agent-tools.md`. It covers developer-agent tools, such as the servers in this issue. It does not cover the product MCP server. Link `docs/contributing/architecture/mcp.md` for that.
4. Adopt `mcp_config`.

## Acceptance criteria

- `claude mcp list` in the repo shows the servers.
- `gitleaks` finds no secret in the files.

## Verify

```bash
mise exec -- gitleaks dir .mcp.json .cursor/mcp.json --redact
```
