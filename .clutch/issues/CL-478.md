# CL-478: Read the goal line of an issue from the head commit

## Goal

`namesGoal` reads `goal:` only from the frontmatter of the issue file at the head commit.

## Context

- `namesGoal` in `tools/check-scope.ts` reads `goal:` from anywhere in an issue file.
- It reads the working tree, not the head commit.
- `statesHandTest` in the same file already reads the frontmatter at the head commit.

## Steps

1. Branch `clutch/cl-478-goal-from-frontmatter`.
2. Change `namesGoal` to read the frontmatter at the head commit, as `statesHandTest` does.
3. Add a test: a `goal:` line in the body does not count.
4. Add a test: a `goal:` line in the frontmatter at the head commit counts.
5. Find out first: the test file for `tools/check-scope.ts`, and add the tests there.

## Files

- `tools/check-scope.ts`
- Its test file. Find out first: the name.

## Acceptance criteria

- A `goal:` line in the body does not name a goal.
- A `goal:` line in the frontmatter at the head commit names a goal.
- `namesGoal` does not read the working tree.
