# CL-504: HUMAN GATE: Run a weekly cross-repo doctor digest

## Goal

Every Monday, a workflow writes doctor and metrics summaries for Clutch, Neighborhood and Bar Savvy to its job summary.

## Gate

Reading the other repositories from Actions needs a token with read access to them. Adding that secret is a credential change.

## Steps (agent)

1. Prepare `.github/workflows/weekly-digest.yml`. For each repo in `clutch.yaml` `fleet`, it runs `clutch doctor --remote --json` and `clutch metrics`, and writes both to `$GITHUB_STEP_SUMMARY`.
2. Ask Brendan in the PR to add a read-only cross-repo token as an Actions secret, and name the secret in the workflow.

## Acceptance criteria

- One run's job summary shows the digest for each repo in `fleet`.

## Verify

```bash
gh workflow run weekly-digest.yml
```
