# CL-504: HUMAN GATE: Add Bix secrets to Actions and run a weekly cross-repo doctor digest

## Goal

Every Monday, Bix receives doctor and metrics summaries for Clutch, Neighborhood and Bar Savvy.

## Gate

Adding secrets is a credential change.

## Steps (agent)

1. Prepare `.github/workflows/weekly-digest.yml`. For each repo in `clutch.yaml` `fleet`, it runs `clutch doctor --remote --json` and `clutch metrics`, then `clutch notify status`.
2. Ask Brendan to add `BIX_WEBHOOK_URL` and `BIX_WEBHOOK_AUTH_HEADER` as Actions secrets.

## Acceptance criteria

- One digest message arrives in Bix.

## Verify

```bash
gh workflow run weekly-digest.yml && gh run watch
```
