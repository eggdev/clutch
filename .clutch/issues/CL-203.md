# CL-203: Add .cursor/environment.json and a devcontainer

## Goal

Cloud agents and fresh machines boot the repo with one command.

## Steps

1. Branch `clutch/cl-203-cloud-env`.
2. Add `.cursor/environment.json`: an install step `curl https://mise.run | sh && ~/.local/bin/mise install && ~/.local/bin/mise exec -- bun install --frozen-lockfile`, and a start step that runs nothing long-lived.
3. Add `.devcontainer/devcontainer.json` on a Debian base image, with a `postCreateCommand` that installs mise and runs `mise install && mise exec -- bun install`.
4. Adopt `cloud_agent_vm`.

## Acceptance criteria

- A Cursor background agent or `devcontainer up` reaches a green `bun run validate`. Record the run link or log in the PR.

## Verify

```bash
npx --yes @devcontainers/cli up --workspace-folder . && npx --yes @devcontainers/cli exec --workspace-folder . mise exec -- bun run validate
```

## Notes

- `mise.toml` installs the clutch binary from GitHub (`github:eggdev/clutch`). An unauthenticated install can hit GitHub rate limits in a cloud VM. Set `GITHUB_TOKEN` in the environment.
