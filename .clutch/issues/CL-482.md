# CL-482: Run the weekly digest once and read its owner findings section

## Goal

One run of the weekly digest workflow shows the owner findings section for each fleet repository. Fix what it shows.

## Context

- CL-472 added `tools/github/owner-findings-digest.ts`.
- CL-472 also added a step in `.github/workflows/weekly-digest.yml`.
- A local read-only run on 2026-11-12 listed 70 owner findings on 12 merged pull requests.
- No workflow run has printed the section yet.

## Steps

1. Branch `clutch/cl-482-digest-run`.
2. Find out first: whether `.github/workflows/weekly-digest.yml` has a `workflow_dispatch` trigger. If it has none, add one.
3. Run the workflow once with `gh workflow run`. Find out first: whether the run needs the change on `main`.
4. Read the owner findings section in the run summary for each fleet repository.
5. Fix what the section shows. Add a test for each fix.

## Files

- `.github/workflows/weekly-digest.yml`
- `tools/github/owner-findings-digest.ts`

## Acceptance criteria

- One run of the workflow shows the owner findings section for each fleet repository.
- Each section shows the owner findings of its repository.

## Verify

- `gh run view` on the run shows the section for each fleet repository.
- `mise exec -- bun run validate`
