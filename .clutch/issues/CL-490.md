# CL-490: Hold a pull request that weakens a data-form journey

## Goal

A pull request that removes or weakens a step of a `*.journey.ts` file waits for the owner, the same as one that weakens a `*.pw.ts` journey.

## Context

- The council review of 2026-11-13 found this gap at head `8563977b`. The owner approved the fix on 2026-11-14.
- `tools/github/weaker-journeys.ts` holds a pull request that weakens a journey. Its pattern `journeyFile` matches only `*.pw.ts` and `*.maestro.yaml`.
- Since v1.0.0 a journey is a list of steps in `features/<name>/journeys/<id>.journey.ts`. The only journey of the template is `features/notes/journeys/notes-sync.journey.ts`, and the pattern does not match it.
- So an agent can delete a `see(...)` step, or the whole file, and the pull request merges with no person.
- The steps are in `packages/journeys/testing/steps.ts`. The Maestro flow of a native run is compiled from the same steps, by `tools/journeys/maestro.ts`.

## Steps

1. Branch `clutch/cl-490-weaker-data-journeys`.
2. Find out first: how `weaker-journeys.ts` reads the outcomes and assertions of a `*.pw.ts` file, and which steps of `steps.ts` prove something (for example `see`, `gone`, `holds`, `serverHolds`, `settled`, `accessible` and `shot`).
3. Find out first: each other tool that finds journey files by `.pw.ts` only. Fix it here when the fix is one pattern. File an issue when it is more.
4. Make `journeyFile` match `*.journey.ts`.
5. Read the step list of a `*.journey.ts` file from its syntax tree. A journey is weaker when it loses a step that proves something, when such a step expects something else, or when a step moves into `webOnly`.
6. Keep the rule for a rename: a new label of a button or a field in a step that only acts changes nothing.
7. Add tests in `tools/github/weaker-journeys.test.ts`.
8. Update the docs page that describes the weaker-journey hold.

## Files

- `tools/github/weaker-journeys.ts`
- `tools/github/weaker-journeys.test.ts`
- `docs/principles/proof-gates-code.md`
- The docs page that owns the weaker-journey hold. Find out first: its name.

## Acceptance criteria

- A test deletes one `see(...)` step from the text of `notes-sync.journey.ts`, and the check returns a reason that names the journey.
- A deleted `*.journey.ts` file returns a reason.
- A step that moves into `webOnly` returns a reason.
- A new label in a `tap` step returns no reason.
- The checks for `*.pw.ts` and `*.maestro.yaml` files still pass their tests.
