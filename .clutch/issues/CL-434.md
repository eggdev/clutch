# CL-434: List the web apps in a fixed order in the several-apps message

## Goal

`tools/journeys/run.test.ts` and `tools/journeys/web-app.test.ts` pass on every machine. They failed in CI on #202, #207 and #208, and passed alone and on `main`.

## Context

- `webAppOf` in `tools/journeys/web-app.ts` lists the candidate apps in the order that the directory read returns them. That order depends on the file system.
- The tests expect `apps/web, apps/admin`. CI on 2026-11-04 read `apps/admin, apps/web`.
- The friction log has this flake from 2026-11-04 as "order- or environment-dependent".

## Steps

1. Sort the folders in the several-apps message.
2. Make the tests expect the sorted order.

## Files

- `tools/journeys/web-app.ts`
- `tools/journeys/run.test.ts`, `tools/journeys/web-app.test.ts`

## Acceptance criteria

- The message lists the apps in sorted order on each file system.
- `mise exec -- bun run validate` passes.

## Verify

```bash
mise exec -- bun test tools/journeys/
```
