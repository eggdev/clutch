# CL-209: Merge 80% of PRs with no human

## Goal

80% of PRs merge with no human, on Clutch and on each project. Only the hard
core needs Brendan. Rules start permissive and tighten only on evidence
(Brendan, 2026-11-02).

## Context

At the step `low`, 18 of the 24 PRs merged from #100 to #131 were
`one-way-door`, mostly for agent skills, `clutch.yaml`, `tools/github` and
the guardrail list. #132 merged decision record 0001 as `low`, with no review.

## Steps

1. Narrow the one-way-door tier of `.clutch/risk.yaml` to the hard core: the
   merge gate, credentials, auth, migrations, billing, infra, and decision
   records and policy docs. Every other path is `medium`.
2. Add `lines` to a risk rule, so a workflow's `permissions:`, environment or
   secrets, and the `automerge` section of `clutch.yaml`, are one-way-door,
   and the rest of those files is not.
3. Add `.clutch/ratchets.json` (lane B, CL-302b) and `packages/journeys/**`
   (lane D, #136) to the guardrail list.
4. Set `automerge.step: medium`. Record the policy as decision record 0002,
   which amends 0001. Set the P2 exit in `.clutch/PLAN.md` to 80%.

## Files

- `.clutch/risk.yaml`, `apps/cli/src/risk/tiers.ts`, `risk-command.ts` and tests
- `tools/codeowners.ts` and its test, `.github/CODEOWNERS`, `tools/guardrail-files.json`
- `clutch.yaml`, `.clutch/PLAN.md`, `docs/contributing/decisions/`
- The docs that said a person reviews each guardrail file

## Acceptance criteria

- A one-line change to agent skills, a check script, lint config or a
  workflow step is `medium`. A workflow `permissions:` line is `one-way-door`.
- Of the 24 PRs merged from #100 to #131, 15 would merge with no human.

## Verify

`mise exec -- bun run validate`, and `clutch risk` on each PR of the stack.
