# CL-221: Turn each revert into a regression test in gardening

## Goal

The weekly gardening pass turns each revert of an auto-merged PR into a
regression test, and plans the re-land.

## Context

When auto-merge's PR is reverted, the Revert workflow files a `risk-tighten`
issue (`tools/github/revert.ts`, `tightenBody`). Nothing then adds the test that
would have caught the break, or plans how the PR can merge again. The gardening
agent already reads merged PRs and open issues, so it closes this loop. See
`docs/contributing/operations/rollback.md#tighten-after-a-revert`.

## Steps

1. Add the reverts, the open `risk-tighten` issues and the reverted PRs to the
   gardening prompt in `.github/workflows/gardening.yml`. Only the prompt text
   changes.
2. The pass takes the reverts first, counts them toward the 3 items, and adds a
   regression test for each one. It names the reverted PR in a comment above the
   test.
3. The body has a "Reverts" section: the reverted PR, its guarding test, and a
   2-3 line re-land plan. A tightening of `.clutch/risk.yaml` stays a proposal.
4. Document the step in `docs/contributing/harness-engineering.md#weekly-gardening`
   and the follow-up in `docs/contributing/operations/rollback.md#tighten-after-a-revert`.

## Files

- `.github/workflows/gardening.yml` (the `prompt:` text only)
- `docs/contributing/harness-engineering.md`
- `docs/contributing/operations/rollback.md`

## Acceptance criteria

- The gardening prompt names the reverts (`revert/` head branches) and the open
  `risk-tighten` issues, and says reverts come first.
- The prompt asks for a regression test per revert, named with the reverted PR,
  and a "Reverts" section in the body with a re-land plan.
- `.clutch/risk.yaml` is named as a proposal, never an edit.
- No line outside the prompt text changes in the workflow: `claude_args`,
  `--allowedTools`, `permissions:`, `environment:`, `secrets.`, and the triggers
  stay as they were.
- `harness-engineering.md#weekly-gardening` and `rollback.md#tighten-after-a-revert`
  each carry the new step.
