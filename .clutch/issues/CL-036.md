# CL-036: Close the gaps the P0 audit found

## Goal

Fix what a read-only audit of every P0 acceptance criterion found on 2026-10-30, so P0 is done in fact and not only in the tracker.

## Context

Four Haiku audits read every P0 issue against the repository. 33 of 38 issues met their criteria and 5 met them in part. Brendan approved these fixes on 2026-10-30. The doctor false positives are CL-038, and the release push to a protected `main` is CL-039.

## Steps

1. Tracker rule: a PR's last commit sets its issue to `done`, and the merge makes it true. Update `.clutch/README.md` and `.agents/skills/deliver/references/pull-requests.md`. A merged PR no longer shows `review` on `main`.
2. CI: a `commits` job in `ci.yml` checks each PR commit subject with `tools/hooks/commit-msg.ts`, because `--no-verify` skips the hook (CL-031 was local only).
3. The reusable doctor workflow runs on each Clutch PR through `clutch-self-test.yml`. When the caller is Clutch, it runs the CLI from the caller's commit (CL-017 had no run).
4. CODEOWNERS covers `AGENTS.md`, `CLAUDE.md` and `.agents/skills/`.
5. A managed root `CLAUDE.md` imports `AGENTS.md`, so Claude Code reads the agent index (CL-801 C4).
6. Stale text: the sync error no longer names `--latest`. The `risk_tier_automerge` waiver points at CL-404, which builds auto-merge. The CL-029 record names the test file it missed.
7. CL-101 is `done`: PR #48 merged.
