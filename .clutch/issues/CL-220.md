# CL-220: Judge a red main by its required checks in auto-revert

## Goal

Auto-revert judges a red main by the same checks as auto-merge and the red-main
metric: the required checks of the default branch, plus `autoRevert.watch`.

## Context

Auto-revert read the conclusion of the whole CI run. Neighborhood's CI has a
non-required `production` job that fails on every push, so no run was green,
auto-revert never reverted, and auto-merge kept merging.

## Steps

1. Read the required checks and the latest job of each check with
   `tools/github/main-checks.ts`, a copy of auto-merge's private helpers.
2. Judge green before and red now by those checks, plus `autoRevert.watch`.
3. Add `autoRevert.watch` to the clutch.yaml schema and document it.

## Files

- `tools/github/auto-revert.ts`, `tools/github/auto-revert.test.ts`
- `tools/github/main-checks.ts`, `tools/github/main-checks.test.ts`
- `apps/cli/src/clutch-config/schema.ts`, `schema.test.ts`
- `apps/cli/README.md`, `docs/contributing/operations/rollback.md`

## Acceptance criteria

- A required check red after required green reverts the auto-merged PR.
- A failed job that is not required, such as `production`, does not revert.
- `autoRevert.watch: [production]` makes a failed production job revert.
- A bad `autoRevert` value fails config validation.

## Verify

`mise exec -- bun test tools/github apps/cli/src/clutch-config` and
`mise exec -- bun run validate`.
