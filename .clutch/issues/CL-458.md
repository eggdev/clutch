# CL-458: Take the model out of the merge decision

## Goal

The merge decision gives the same answer on the same head. No model verdict, outage or missing credential holds a PR.

## Context

System review, 2026-11-08: the visual verdict failed `agent-review`, no structured output failed it, and a missing credential failed it. Pixel baselines stay as the deterministic check.

## Steps

1. Make the visual report warn and exit 0.
2. Make agent review warn when it returns no result, and give a notice with no credential.
3. Remove `agent-review` from the required checks in the ruleset, the judge and the main checks.

## Files

- `tools/journeys/visual-review.ts`, `.github/workflows/agent-review.yml`, `.github/rulesets/main.json`, `tools/github/auto-merge.ts`, `tools/github/main-checks.ts`, `clutch.yaml`

## Acceptance criteria

- A failed agent review gives no blocker.
- `bun run validate` passes.
