# CL-404: Add the low-risk auto-merge workflow in dry-run mode

## Goal

Low-risk agent PRs that pass every required check and the agent review get queued for merge without Brendan.

## Steps

1. Branch `clutch/cl-404-automerge`.
2. Add `.github/workflows/auto-merge.yml`. It triggers when a PR is labeled, on `check_suite` completed and on `pull_request_review`.
   - Conditions: the label is `risk/low`, size is not XL, the PR is not a draft, the author is on the agent allowlist in `clutch.yaml` `automerge.authors`, and every required check is green.
   - Action: when `clutch.yaml` `automerge.mode` is `dry-run`, comment "would auto-merge". When it is `on`, run `gh pr merge --auto --squash`.
3. Ship with `mode: dry-run`. Turning it on is part of CL-405.

## Acceptance criteria

- 5 low-risk PRs get the dry-run comment, and no medium or higher PR does.

## Verify

```bash
gh pr list --label risk/low --state all --limit 10
```
