# CL-022: Remove the Nx remote cache and keep the local cache

## Goal

Remove the Cloudflare Nx remote cache from Clutch. Nx keeps its local cache. A template does not need a shared cache, and the worker kept the old `project-template` name alive (decision by Brendan, 2026-10-29).

## Context

- `apps/nx-cache` is a Cloudflare Worker on R2. `.github/workflows/nx-cache.yml` deploys it. `ci.yml` turns it on when a probe passes.
- The kickoff skill tells each project to set up its own cache. `docs/contributing/setup/nx.md` holds the setup steps.
- The deployed worker, the R2 bucket, and the GitHub secrets and variables (`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `NX_CACHE_URL`, `NX_CACHE_WRITE_TOKEN`, `NX_CACHE_READ_TOKEN`) live outside the repo. Deleting them is a human gate.

## Steps

1. Branch `clutch/cl-022-drop-remote-cache`.
2. Delete `apps/nx-cache/` and `.github/workflows/nx-cache.yml`.
3. Remove the "Turn on the Nx remote cache" step from `.github/workflows/ci.yml`.
4. Remove the `nx-cache` primitive, its `template.files.yaml` entry, its `tsconfig.json` reference, and the `wrangler` and `@cloudflare/workers-types` dev dependencies.
5. Remove the "Remote cache" section from `docs/contributing/setup/nx.md`, the cache step from the kickoff skill, the README section, and the Cloudflare section in `docs/contributing/operations/operator-accounts.md`.
6. Change the pr-recap example in `.agents/skills/pr-recap/references/block-format.md` to primitives that exist.
7. Update CL-016 and CL-105, which name the remote cache.
8. `mise exec -- bun install`, format, validate.

## Files

- edit `.github/workflows/ci.yml`, `package.json`, `bun.lock`, `tsconfig.json`, `template.files.yaml`
